# [C++] 정수형 변수의 종류와 메모리 최적화

C++ 학습의 첫 단계로, 데이터를 저장하는 **변수(Variable)**의 선언 방법과 다양한 정수형 타입들의 크기, 그리고 **오버플로우** 현상에 대해 정리

---

## 1. 소스 코드 (Source Code)

다양한 정수형 변수를 선언해 보고, 최대값을 넘겼을 때 발생하는 오버플로우 현상을 확인하는 예제

```cpp
#include <iostream>
using namespace std;

// 전역 변수 (Global Variable)
// 초기값이 있으면 .data 영역, 없거나 0이면 .bss 영역에 저장됨
int hp = 100;

int main()
{
    // 정수형 타입의 종류와 크기
    char a;             // 1 byte (-128 ~ 127)
    short b;            // 2 byte (-32,768 ~ 32,767)
    int c;              // 4 byte (약 -21억 ~ 21억)
    long long d;        // 8 byte (매우 큼) (__int64)

    // Unsigned (양수 전용)
    unsigned char ua;       // 1 byte (0 ~ 255)
    unsigned short ub;      // 2 byte (0 ~ 65,535)
    unsigned int uc;        // 4 byte (0 ~ 42억)
    unsigned long long ud;  // 8 byte

    // 오버플로우 (Overflow) 테스트
    b = 32767;              // short의 최대값 (0x7FFF)
    b = b + 1;              // 1을 더함
    cout << "b (Overflow) = " << b << "\n";

    // 원인 분석:
    // 0111 1111 1111 1111 (32767)
    // +                 1
    // -------------------
    // 1000 0000 0000 0000 (-32768, 최상위 비트가 1이 됨)

    // 언더플로우 (Underflow) 테스트
    ub = 0;                 // unsigned short의 최소값
    ub = ub - 1;            // 1을 뺌
    cout << "ub (Underflow) = " << ub << "\n";
    // 결과는 65535 (최대값)으로 돌아감

    cout << "체력이 " << hp << " 남았습니다.\n";

    return 0;
}
```

## 2. 이론 정리 (Study Notes)

### 1) 변수 선언과 메모리 (Variable & Memory)
프로그래밍은 본질적으로 **데이터(Data)를 저장하고 로직(Logic)으로 가공**하는 것

* **변수 선언 문법:** `[타입] [이름] = [초기값];`
* **전역 변수의 저장 위치:** (어셈블리 공부 내용과 연결)
  * **.data 영역:** `int hp = 100;` 처럼 **0이 아닌 초기값**이 있는 경우
  * **.bss 영역:** `int mp;` 처럼 초기값이 없거나 0인 경우

### 2) 정수형 데이터 타입 (Integer Types)
왜 `int` 하나만 쓰지 않고 여러 타입이 존재할까? 상황에 맞는 크기를 골라 쓰기 위함

| 타입 (Type) | 크기 (Byte) | 비트 (Bit) | 표현 범위 (Signed) | 사용처 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **char** | 1 | 8 | -128 ~ 127 | 문자, 작은 상태값 |
| **short** | 2 | 16 | -32,768 ~ 32,767 | 아이템 개수, 스탯 |
| **int** | 4 | 32 | 약 -21억 ~ 21억 | 일반적인 정수 연산 |
| **long long** | 8 | 64 | 매우 큼 | 게임 머니, 경험치 |

* **Signed (기본):** 음수와 양수 모두 표현. 최상위 비트(MSB)를 부호 비트로 사용
* **Unsigned:** 양수만 표현 (`unsigned int` 등). 음수 영역만큼 양수 범위가 2배로 늘어남

### 3) 오버플로우와 언더플로우

변수가 담을 수 있는 범위를 넘어설 때 발생하는 현상. 값이 순환(Cycle)하는 특성을 가짐

* **오버플로우 (Overflow):** 최대값을 넘어가면 가장 작은 값(음수)으로 돌아가 버리는 현상
  > 예: `short` 32,767 + 1 = **-32,768**
* **언더플로우 (Underflow):** 최소값보다 작아지면 가장 큰 값(양수)으로 돌아가 버리는 현상
  > 예: `unsigned` 0 - 1 = **최대값(42억 or 65535 등)**

## 3. 종합 의견 (Review)

### 1) 왜 4바이트(int)로 통일하지 않는가?
요즘 PC 성능이 좋으니 `int`만 써도 되지 않을까 싶지만, 개발 환경에 따라 다름
* **콘솔/모바일:** 하드웨어 리소스(메모리)가 제한적이므로 최대한 아껴야 함
* **온라인 게임:** 서버와 데이터를 주고받을 때 패킷 크기를 줄여야 함 (예: 동접 1만 명일 때 4바이트 대신 1바이트를 쓰면 데이터 전송량이 1/4로 줄어듦)

### 2) Unsigned 사용에 대한 고찰
> "체력이나 레벨은 음수가 없으니 무조건 `unsigned`를 써야 할까?"

* **장점:** 표현 범위가 양수 쪽으로 2배 넓어짐
* **단점:** 연산 과정에서 실수로 `0 - 1` 같은 상황이 발생하면 **엄청나게 큰 값**으로 변해버리는 버그(언더플로우)가 발생하기 쉬움
* **결론:** 팀이나 개인의 코딩 스타일(Convention)에 따라 다르지만, **연산 안전성**을 위해 일반적인 수치는 그냥 `int`(signed)를 사용하는 경우도 많음

### 3) 팁 (Tip)
* **호환성:** C++ 표준에서는 `__int64` 대신 **`long long`**을 사용하는 것이 호환성에 좋음 (`__int64`는 마이크로소프트 전용 키워드)
* **디버깅:** 게임 테스트 중 숫자가 갑자기 말도 안 되게 큰 값이 나오거나(언더플로우), 뜬금없이 음수가 나온다면(오버플로우) 데이터 타입의 범위를 확인하기!

## 4. 심화 학습 (Deep Dive)

### 1) 내 변수의 크기 확인하기 (`sizeof`)
"정말 `int`가 4바이트일까?" 궁금하다면 `sizeof` 연산자로 직접 확인하기

```cpp
cout << "int size: " << sizeof(int) << " bytes" << endl;     // 4 bytes
cout << "char size: " << sizeof(char) << " bytes" << endl;   // 1 byte
```
### 2) char는 문자가 아니라 '작은 정수'다
`char` 타입에 `'A'`를 넣지만, 컴퓨터는 이를 아스키 코드 값인 정수 **65**로 저장 즉, `char`도 덧셈/뺄셈 연산이 가능

```cpp
char ch = 'A';            // 내부적으로 65 저장
cout << (int)ch << endl;  // 65 출력 (형변환)

ch = ch + 1;              // 65 + 1 = 66 ('B')
cout << ch << endl;       // 'B' 출력
```
