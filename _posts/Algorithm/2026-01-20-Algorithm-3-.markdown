# [Algorithm] 선형 자료 구조 : 배열, 동적 배열, 연결 리스트

---

## 이론 정리
* **자료 구조의 분류**
  * **선형 자료 구조(Linear):** 자료를 순차적으로 나열한 형태 (배열, 연결 리스트, 스택, 큐 등)
  * **비선형 자료 구조(Non-Linear):** 하나의 자료 뒤에 다수의 자료가 올 수 있는 형태 (트리, 그래프 등)

* **배열 (Array)**
  * **특징:** 사용할 방 개수(크기)를 고정하여 계약함. 절대 변경 불가
  * **메모리:** 연속된 주소 공간을 배정받음
  * **장점:** 연속된 방이므로 임의 접근(Random Access)이 빠름
  * **단점:** 방의 추가/축소가 불가능하며, 중간 삽입/삭제 시 데이터를 이동시켜야 하므로 비효율적임

* **동적 배열 (Dynamic Array / Vector)**
  * **특징:** 사용할 방 개수를 유동적으로 관리함
  * **메모리:** 연속된 주소 공간을 사용
  * **문제점:** 공간이 부족할 때 더 큰 곳으로 이사(재할당+복사)해야 하며, 비용이 큼
  * **해결책:** 실제 사용량보다 여유분(Capacity)을 두고 예약(약 1.5배 ~ 2배)하여 이사 횟수를 최소화함
  * **장점:** 유동적인 크기 조절이 가능함
  * **단점:** 배열과 마찬가지로 중간 삽입/삭제는 여전히 비효율적임

* **연결 리스트 (Linked List)**
  * **특징:** 데이터가 연속되지 않은 공간에 흩어져 존재하며, 이를 연결하여 관리함
  * **장점:** 중간 데이터의 삽입/삭제가 매우 효율적임 (연결 고리만 변경하면 됨)
  * **단점:** $N$번째 방을 바로 찾을 수 없음 (임의 접근 불가, 첫 노드부터 순회해야 함)

---

## 종합
* **배열 계열(Array, Dynamic Array)**은 데이터의 물리적 위치가 연속적이므로 인덱스를 통한 조회 속도가 매우 빠름
* **연결 리스트**는 물리적 위치가 불연속적이라 조회는 느리지만, 데이터 구조 변경(삽입/삭제)에는 매우 유연함
* 데이터의 **조회(Search)**가 빈번하다면 배열을, **수정(Modification)**이 빈번하다면 연결 리스트를 선택하는 것이 유리함

---

## Tip
* **임의 접근(Random Access)이란?**
  * $N$번째 데이터가 몇 번째 주소에 있는지 즉시 계산하여 접근할 수 있는 성질임
  * **배열:** `시작 주소 + (데이터 크기 * N)` 공식을 통해 $O(1)$의 시간 복잡도로 접근 가능함
  * **연결 리스트:** 첫 번째 노드부터 화살표(포인터)를 타고 순차적으로 이동해야 하므로 $O(N)$의 시간이 소요됨
