# [Algorithm] 다익스트라(Dijkstra) 최단 경로 알고리즘 구현

가중치가 있는 그래프에서 시작 정점으로부터 다른 모든 정점까지의 최단 경로를 구하는 다익스트라 알고리즘 분석 및 구현체

## 1. 소스 코드 (Source Code)

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <stack>
#include <queue>
using namespace std;

struct Vertex
{
    // 필요 시 정점의 데이터(Data) 보관 용도로 사용
};

vector<Vertex> Vertices;
// 인접 행렬 기반 그래프 (가중치 저장, -1은 연결되지 않음을 의미)
vector<vector<int>> Adjacent;

// 그래프 초기화 및 가중치 간선 구성
void CreateGraph()
{
    Vertices.resize(6);
    // 모든 간선을 -1(연결 안 됨)로 초기화
    Adjacent = vector<vector<int>>(6, vector<int>(6, -1));

    Adjacent[0][1] = 15;
    Adjacent[0][3] = 35;
    Adjacent[1][0] = 15;
    Adjacent[1][2] = 5;
    Adjacent[1][3] = 10;
    Adjacent[3][4] = 5;
    Adjacent[5][4] = 5;
}

// 다익스트라 최단 경로 알고리즘 구현
void Dijikstra(int here)
{
    // 정점과 해당 정점까지의 누적 비용을 묶어 관리하는 구조체
    struct VertexCost
    {
        int vertex;
        int cost;
    };

    // 탐색 대기열 (우선순위 큐 대체용 리스트)
    list<VertexCost> discovered;
    // 시작점으로부터 각 정점까지의 최소 비용을 저장하는 배열 (무한대로 초기화)
    vector<int> best(6, INT32_MAX);
    // 경로 역추적을 위한 부모 노드 배열
    vector<int> parent(6, -1);

    // 시작점 초기화
    discovered.push_back(VertexCost{ here, 0 });
    best[here] = 0;
    parent[here] = here;

    while (discovered.empty() == false)
    {
        // 현재 발견된 후보들 중 가장 비용이 적은 정점 탐색 (선형 탐색)
        list<VertexCost>::iterator bestIt;
        int bestCost = INT32_MAX;

        for (auto it = discovered.begin(); it != discovered.end(); it++)
        {
            if (it->cost < bestCost)
            {
                bestCost = it->cost;
                bestIt = it;
            }
        }

        int cost = bestIt->cost;
        here = bestIt->vertex;
        // 선택된 최적의 정점을 대기열에서 제거
        discovered.erase(bestIt);

        // 이미 더 짧은 경로를 통해 방문 및 처리된 정점이라면 스킵 (최적화)
        if (best[here] < cost)
        {
            continue;
        }

        // 현재 정점과 연결된 모든 인접 정점 탐색
        for (int there = 0; there < 6; there++)
        {
            // 간선이 존재하지 않으면 스킵
            if (Adjacent[here][there] == -1)
            {
                continue;
            }

            // 현재 정점을 거쳐서 가는 새로운 경로의 비용 계산
            int nextCost = best[here] + Adjacent[here][there];

            // 기존에 발견된 경로 비용보다 크거나 같으면 갱신 불필요
            if (nextCost >= best[there])
            {
                continue;
            }

            // 더 나은 경로를 찾았으므로 대기열에 추가 및 정보 갱신 (Relaxation)
            discovered.push_back(VertexCost{ there, nextCost });
            best[there] = nextCost;
            parent[there] = here;
        }
    }
}

int main()
{
    CreateGraph();
    // 0번 정점을 시작점으로 다익스트라 알고리즘 수행
    Dijikstra(0);

    return 0;
}
```

## 2. 이론 정리 (Study Notes)

다익스트라(Dijkstra) 알고리즘은 하나의 시작 정점으로부터 모든 다른 정점까지의 최단 경로를 찾는 알고리즘
음의 가중치를 가지는 간선이 없을 때만 정상적으로 동작하며, 그리디(Greedy) 방식과 다이나믹 프로그래밍(DP)의 개념이 혼합된 형태를 띰

| 탐색 대기열 구조 | 시간 복잡도 | 장단점 및 특징 |
| :--- | :--- | :--- |
| **선형 배열 / 리스트** | $O(\vert V \vert^2)$ | 구현이 직관적이나, 매번 최소 비용을 찾기 위해 전체를 순회해야 하므로 비효율적임 |
| **우선순위 큐 (Heap)** | $O((\vert V \vert + \vert E \vert) \log \vert V \vert)$ | 삽입/삭제 시 정렬이 유지되어 성능이 우수하며, 실무에서 표준으로 사용됨 |

**비용 갱신(Relaxation) 수식:**

어떤 정점 $u$를 거쳐서 정점 $v$로 가는 경로의 비용이 기존에 알려진 $v$까지의 비용보다 작을 경우 갱신을 수행함
$$d(v) = \min(d(v), d(u) + w(u, v))$$
여기서 $d(v)$는 시작점에서 $v$까지의 최단 거리, $w(u, v)$는 $u$에서 $v$로 가는 간선의 가중치를 의미함

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항
* 너비 우선 탐색(BFS)과 유사하지만, 단순 큐(Queue) 대신 누적 가중치가 가장 적은 노드를 먼저 꺼내는 방식을 사용
* 음수 간선이 포함된 그래프에서는 무한 루프에 빠지거나 잘못된 최단 거리를 도출할 수 있으므로 벨만-포드(Bellman-Ford) 알고리즘을 사용해야 함
* 한 번 방문 처리되어 최단 거리가 확정된 노드는 다시 처리하지 않는 로직(`best[here] < cost`)이 성능 최적화의 핵심

### Tip
* 본문의 소스 코드는 학습을 위해 `std::list`를 순회하며 최소값을 찾도록 구현되었으나, 실무 및 코딩 테스트에서는 반드시 `std::priority_queue`를 사용하여 $O(E \log V)$의 시간 복잡도를 확보해야 함
* 우선순위 큐 사용 시 C++의 `priority_queue`는 기본적으로 최대 힙(Max Heap)이므로, 최소 힙(Min Heap)으로 사용하기 위해 `greater` 비교 연산자를 활용하거나 넣을 때 가중치에 음수(-) 기호를 붙여 넣는 트릭을 자주 사용
* `parent` 배열을 역추적하면 최단 거리 계산뿐만 아니라 실제 이동해야 할 최적의 경로(Path)를 쉽게 복원
