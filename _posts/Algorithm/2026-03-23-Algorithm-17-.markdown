# [Algorithm] A* (A-Star) 기반 미로 최단 경로 알고리즘 구현

휴리스틱(Heuristic) 추정치를 활용하여 다익스트라의 탐색 범위를 최적화한 A* 최단 경로 알고리즘의 원리 분석 및 구현체

## 1. 소스 코드 (Source Code)

```cpp
struct PQNode
{
	bool operator<(const PQNode& other) const { return f < other.f; }
	bool operator>(const PQNode& other) const { return f > other.f; }

	int32	f; // f = g + h (총 예상 비용)
	int32	g; // 시작점으로부터의 누적 이동 비용
	Pos		pos;
};

void Player::AStar()
{
	// A* 알고리즘의 핵심 평가 지표 설정
	// F = G + H (최종 점수, 낮을수록 우선순위 높음)
	// G = 시작점에서 현재 좌표까지 이동하는 데 소요된 실제 누적 비용
	// H = 현재 좌표에서 목적지까지의 예상 잔여 비용 (휴리스틱 추정치)

	Pos start = Position;
	Pos dest = MazeBoard->GetExitPos();

	enum
	{
		DIR_COUNT = 8
	};

	// 8방향 탐색을 위한 방향 벡터 정의
	Pos front[] =
	{
		Pos { -1, 0},	// UP
		Pos { 0, -1},	// LEFT
		Pos { 1, 0},	// DOWN
		Pos { 0, 1},	// RIGHT
		Pos {-1, -1},	// UP_LEFT
		Pos {1, -1},	// DOWN_LEFT
		Pos {1, 1},		// DOWN_RIGHT
		Pos {-1, 1},	// UP_RIGHT
	};

	// 대각선 이동(14)과 직진 이동(10)의 가중치 분리 (피타고라스 비율 근사치 적용)
	int32 cost[] =
	{
		10, 10, 10, 10,
		14, 14, 14, 14
	};

	const int32 size = MazeBoard->GetSize();

	// 탐색 완료 노드 기록용 Closed List (방문 여부 체크)
	vector<vector<bool>> closed(size, vector<bool>(size, false));

	// 각 좌표까지의 최소 비용(F)을 기록하는 배열
	vector<vector<int32>> best(size, vector<int32>(size, INT32_MAX));

	// 경로 역추적을 위한 부모 노드 기록 맵
	map<Pos, Pos> parent;

	// 탐색 대기열인 Open List (F값이 가장 작은 노드부터 추출하는 최소 힙 구성)
	priority_queue<PQNode, vector<PQNode>, greater<PQNode>> pq;

	// 시작 노드 초기화 및 Open List 삽입
	{
		int32 g = 0;
		// 맨해튼 거리 기반 휴리스틱(H) 산출 근사식 적용
		int32 h = 10 * (abs(dest.y - start.y) + abs(dest.x - start.x));
		pq.push(PQNode{ g + h, g, start });
		best[start.y][start.x] = g + h;
		parent[start] = start;
	}

	while (pq.empty() == false)
	{
		// Open List에서 F값이 가장 작은 최적의 후보 노드 추출
		PQNode node = pq.top();
		pq.pop();

		// 이미 방문 처리된 노드(Closed)라면 탐색 스킵
		if (closed[node.pos.y][node.pos.x])
		{
			continue;
		}

		// 우선순위 큐 삽입 시점과 현재 시점의 최소 비용이 다를 수 있으므로 검증
		if (best[node.pos.y][node.pos.x] < node.f)
		{
			continue;
		}

		// 현재 노드 방문 처리 (Closed List 편입)
		closed[node.pos.y][node.pos.x] = true;

		// 목적지 도달 시 탐색 조기 종료
		if (node.pos == dest)
		{
			break;
		}

		// 인접한 8방향 노드 탐색 (Open List 확장)
		for (int32 dir = 0; dir < DIR_COUNT; dir++)
		{
			Pos nextPos = node.pos + front[dir];

			// 맵 경계 밖이거나 장애물인 경우 스킵
			if (CanGo(nextPos) == false)
			{
				continue;
			}

			// 이미 탐색이 완료된 노드라면 스킵
			if (closed[nextPos.y][nextPos.x])
			{
				continue;
			}

			// 다음 노드까지의 새로운 G비용과 휴리스틱 H비용 계산
			int32 g = node.g + cost[dir];
			int32 h = 10 * (abs(dest.y - nextPos.y) + abs(dest.x - nextPos.x));

			// 기존에 발견된 경로 비용보다 크거나 같으면 갱신 불필요
			if (best[nextPos.y][nextPos.x] <= g + h)
			{
				continue;
			}

			// 더 나은 경로를 발견했으므로 정보 갱신 및 Open List 삽입
			best[nextPos.y][nextPos.x] = g + h;
			pq.push(PQNode{ g + h, g, nextPos });
			parent[nextPos] = node.pos;
		}
	}

	// 목적지부터 시작점까지 부모 노드를 추적하며 경로 복원
	Pos pos = dest;

	Path.clear();
	PathIndex = 0;

	while (true)
	{
		Path.push_back(pos);

		// 시작점에 도달하면 역추적 종료
		if (pos == parent[pos])
		{
			break;
		}

		pos = parent[pos];
	}

	// 수집된 경로를 시작점 기준으로 뒤집음
	std::reverse(Path.begin(), Path.end());
}
```

## 2. 이론 정리 (Study Notes)

A* (A-Star) 알고리즘은 다익스트라(Dijkstra) 알고리즘에 목적지까지의 예상 거리를 더하는 휴리스틱(Heuristic) 기법을 결합하여 탐색 효율을 극대화한 길찾기 알고리즘임

### 핵심 평가 수식 (F = G + H)

각 노드의 평가 점수 $F(n)$은 다음과 같은 수식으로 계산되며, 이 값이 작을수록 우선순위 큐에서 먼저 추출됨

$$F(n) = G(n) + H(n)$$

* $G(n)$: 시작 노드에서 현재 노드 $n$까지 이동하는 데 소요된 실제 누적 비용임
* $H(n)$: 현재 노드 $n$에서 목적지까지 남은 예상 비용(휴리스틱)을 의미함
* $F(n)$: 현재 노드를 거쳐 목적지까지 가는 총 예상 비용임

### 주요 길찾기 알고리즘 비교

| 알고리즘 | 탐색 기준 | 시간 복잡도 | 특징 및 장단점 |
| :--- | :--- | :--- | :--- |
| **BFS** | 간선 수 (가중치 동일) | $O(V + E)$ | 구현이 단순하나 간선 가중치가 다를 경우 최단 경로를 보장하지 못함 |
| **Dijkstra** | 누적 비용 $G(n)$ | $O(E \log V)$ | 최단 경로를 완벽히 보장하나 모든 방향으로 탐색이 퍼져 연산량이 많음 |
| **A*** | 총 예상 비용 $F(n)$ | $O(E \log V)$ | 휴리스틱을 통해 목적지 방향으로 탐색을 유도하므로 탐색 노드 수가 현저히 적음 |

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항

* **우선순위 큐를 통한 Open List 관리:** `std::priority_queue`를 활용하여 $F$값이 가장 낮은 노드를 우선적으로 탐색하는 최소 힙(Min-Heap) 구조를 유지해야 함
* **방문 처리(Closed List) 분리:** 한 번 탐색이 완료되어 최소 비용이 확정된 노드는 중복 연산을 방지하기 위해 `closed` 배열로 관리하는 것이 필수적임
* **지연된 갱신(Lazy Deletion) 처리:** C++ 우선순위 큐는 내부 요소 갱신이 불가능하므로, 더 짧은 경로 발견 시 큐에 새로 삽입하고 Pop하는 시점에 `best` 배열과 비교하여 기존의 낡은 데이터를 무시하는 기법을 사용함

### Tip

* **휴리스틱 함수(H)의 선택:** 대각선 이동이 가능한 격자 환경에서는 단순 맨해튼 거리(Manhattan Distance)보다 대각선 거리(Diagonal Distance) 연산을 활용하는 것이 A* 알고리즘의 탐색 정확도와 성능을 높임
* **정수형 가중치 최적화:** 직진은 10, 대각선은 14 ($10 \times \sqrt{2} \approx 14.14$)로 설정하면 부동소수점 연산(float/double) 오버헤드를 없애고 정밀하고 빠른 경로 탐색이 가능함
* **메모리 단편화 개선:** 맵 크
