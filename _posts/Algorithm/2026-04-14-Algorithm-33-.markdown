숫자가 삼각형 모양으로 놓여 있을 때 꼭대기에서 출발해 바로 아래 또는 오른쪽 아래로 이동한다고 하자. 맨 아래에 도착할 때까지 지나온 숫자의 합이 최대가 되는 경로를 찾는 문제다.

```text
          7
        3   8
      8   1   0
    2   7   4   4
  4   5   2   6   5
```

한 번 이동할 때 선택지는 두 개뿐이지만, 모든 경로를 직접 확인하면 층이 늘어날 때마다 경우의 수가 두 배 가까이 증가한다. 같은 칸에 여러 경로가 합쳐진다는 점을 이용하면 중복 계산을 없앨 수 있다.

## 좌표와 이동 규칙부터 정리한다

행과 열을 모두 0부터 시작하는 인덱스로 나타내면 `row`번째 행에는 `row + 1`개의 칸이 있다.

```text
triangle[0][0]

triangle[1][0]  triangle[1][1]

triangle[2][0]  triangle[2][1]  triangle[2][2]
```

`(row, column)`에서 다음 행으로 이동할 수 있는 위치는 다음 두 곳이다.

```text
왼쪽 아래   : (row + 1, column)
오른쪽 아래 : (row + 1, column + 1)
```

반대로 현재 칸으로 들어올 수 있는 이전 위치를 생각하면 점화식을 만들기 쉽다.

```text
왼쪽 위 : (row - 1, column - 1)
오른쪽 위: (row - 1, column)
```

단, 삼각형의 양쪽 가장자리에는 이전 위치가 하나만 존재한다.

## 현재 칸까지의 최대 합을 상태로 둔다

Bottom-up 방식의 상태를 다음과 같이 정의하자.

```text
dp[row][column] = 꼭대기에서 현재 칸까지 내려왔을 때 얻을 수 있는 최대 합
```

현재 칸이 양쪽 가장자리가 아니라면 왼쪽 위와 오른쪽 위 중 더 큰 경로에 현재 값을 더한다.

$$
dp[r][c] = triangle[r][c] + \max(dp[r-1][c-1], dp[r-1][c])
$$

꼭대기의 초기값은 삼각형의 첫 번째 값이다.

$$
dp[0][0] = triangle[0][0]
$$

## 가장자리에는 별도의 조건이 필요하다

왼쪽 끝인 `column == 0`에는 오른쪽 위 칸만 존재한다.

$$
dp[r][0] = triangle[r][0] + dp[r-1][0]
$$

오른쪽 끝인 `column == row`에는 왼쪽 위 칸만 존재한다.

$$
dp[r][r] = triangle[r][r] + dp[r-1][r-1]
$$

이를 그대로 구현하면 다음과 같다.

```cpp
long long MaximumTrianglePath(const std::vector<std::vector<int>>& triangle)
{
    if (triangle.empty())
    {
        return 0;
    }

    std::vector<std::vector<long long>> dp(triangle.size());
    dp[0] = {triangle[0][0]};

    for (std::size_t row = 1; row < triangle.size(); ++row)
    {
        dp[row].resize(row + 1);

        for (std::size_t column = 0; column <= row; ++column)
        {
            if (column == 0)
            {
                dp[row][column] = dp[row - 1][column] + triangle[row][column];
            }
            else if (column == row)
            {
                dp[row][column] = dp[row - 1][column - 1] + triangle[row][column];
            }
            else
            {
                dp[row][column] = std::max(dp[row - 1][column - 1], dp[row - 1][column]) + triangle[row][column];
            }
        }
    }

    return *std::max_element(dp.back().begin(), dp.back().end());
}
```

최대 경로가 어느 칸에서 끝나는지는 정해져 있지 않다. 따라서 마지막 행 전체에서 최댓값을 찾아야 한다.

## 실제 값으로 계산 과정을 확인한다

앞의 삼각형을 위에서부터 계산하면 DP 테이블은 다음과 같이 채워진다.

```text
triangle                 dp

        7                         7
      3   8                    10  15
    8   1   0                18  16  15
  2   7   4   4            20  25  20  19
4   5   2   6   5        24  30  27  26  24
```

마지막 행의 최댓값은 30이다. 이에 해당하는 경로 하나는 `7 → 3 → 8 → 7 → 5`다.

삼각형에 총 $N$개의 칸이 있다면 각 칸을 한 번씩 처리하므로 시간 복잡도와 공간 복잡도는 모두 $O(N)$이다. 높이를 $H$로 표현하면 칸의 수가 약 $H^2/2$이므로 $O(H^2)$라고도 쓸 수 있다.

## 아래에서 위로 계산하면 경계 처리가 단순해진다

이번에는 상태를 다른 방향으로 정의해 보자.

```text
dp[column] = 현재 행의 해당 칸에서 출발해 바닥까지 내려갈 때 얻는 최대 합
```

맨 아래 행을 초기값으로 복사한 뒤, 한 행씩 위로 올라가며 바로 아래의 두 결과 중 큰 값을 선택한다.

```cpp
long long MaximumTrianglePathCompact(const std::vector<std::vector<int>>& triangle)
{
    if (triangle.empty())
    {
        return 0;
    }

    std::vector<long long> dp(triangle.back().begin(), triangle.back().end());

    for (std::size_t row = triangle.size() - 1; row > 0; --row)
    {
        for (std::size_t column = 0; column < row; ++column)
        {
            dp[column] = std::max(dp[column], dp[column + 1]) + triangle[row - 1][column];
        }
    }

    return dp[0];
}
```

아래에서 위로 올라갈 때는 모든 칸에 두 자식이 존재하므로 양쪽 가장자리를 따로 나눌 필요가 없다. 또한 다음 계산에 바로 아래 행만 필요하므로 1차원 배열 하나로 충분하다.

시간 복잡도는 $O(H^2)$로 같고, 추가 공간은 $O(H)$로 줄어든다. 다만 배열을 덮어쓰므로 경로까지 복원하려면 선택 정보를 별도로 저장해야 한다.

## 음수가 있어도 올바르게 계산해야 한다

모든 값이 양수라고 가정하고 DP 배열을 0으로 초기화하면 음수 입력에서 존재하지 않는 경로를 선택하는 문제가 생길 수 있다.

```text
     -1
   -2  -3

올바른 최대 합: -3
잘못된 초기값 0을 후보로 사용하면: -1 또는 0처럼 잘못 계산될 수 있음
```

앞의 두 구현은 실제로 도달 가능한 칸의 값만 이용하므로 음수도 처리할 수 있다. 도달할 수 없는 칸까지 포함하는 직사각형 DP 배열을 사용한다면 그 칸은 0이 아니라 충분히 작은 값으로 표시하고, 덧셈 전에 유효한 상태인지 확인해야 한다.

## 최대 경로를 복원한다

위에서 아래로 계산할 때 현재 칸이 어느 부모에서 왔는지를 저장하면 경로를 되찾을 수 있다.

```cpp
std::vector<int> RestoreMaximumTrianglePath(const std::vector<std::vector<int>>& triangle)
{
    if (triangle.empty())
    {
        return {};
    }

    std::vector<std::vector<long long>> dp(triangle.size());
    std::vector<std::vector<int>> parent(triangle.size());
    dp[0] = {triangle[0][0]};
    parent[0] = {-1};

    for (std::size_t row = 1; row < triangle.size(); ++row)
    {
        dp[row].resize(row + 1);
        parent[row].resize(row + 1);

        for (std::size_t column = 0; column <= row; ++column)
        {
            if (column == 0)
            {
                dp[row][column] = dp[row - 1][column] + triangle[row][column];
                parent[row][column] = 0;
            }
            else if (column == row || dp[row - 1][column - 1] >= dp[row - 1][column])
            {
                dp[row][column] = dp[row - 1][column - 1] + triangle[row][column];
                parent[row][column] = static_cast<int>(column - 1);
            }
            else
            {
                dp[row][column] = dp[row - 1][column] + triangle[row][column];
                parent[row][column] = static_cast<int>(column);
            }
        }
    }

    int column = static_cast<int>(std::max_element(dp.back().begin(), dp.back().end()) - dp.back().begin());
    std::vector<int> path(triangle.size());

    for (std::size_t row = triangle.size(); row > 0; --row)
    {
        path[row - 1] = triangle[row - 1][column];
        column = parent[row - 1][column];
    }

    return path;
}
```

두 부모가 같은 합을 만들면 이 구현은 왼쪽 위 부모를 선택한다. 최대 합 경로가 여러 개일 수 있으므로 복원 결과는 그중 하나다.

## 입력의 모양도 검증 대상이다

알고리즘은 `row`번째 행에 정확히 `row + 1`개의 값이 있다고 가정한다. 외부 입력을 그대로 받는 프로그램이라면 계산 전에 삼각형 모양인지 확인해야 한다.

```cpp
bool IsTriangle(const std::vector<std::vector<int>>& triangle)
{
    for (std::size_t row = 0; row < triangle.size(); ++row)
    {
        if (triangle[row].size() != row + 1)
        {
            return false;
        }
    }

    return true;
}
```

행 길이가 잘못된 입력을 검증하지 않으면 범위를 벗어난 인덱스 접근으로 이어질 수 있다. 합의 범위도 `int`를 넘을 수 있으므로 누적 결과는 `long long`으로 저장했다.

## 전체 검증 코드

```cpp
#include <algorithm>
#include <cassert>
#include <vector>

// MaximumTrianglePath, MaximumTrianglePathCompact,
// RestoreMaximumTrianglePath, IsTriangle 구현은 앞의 코드와 같다.

int main()
{
    std::vector<std::vector<int>> triangle{
        {7},
        {3, 8},
        {8, 1, 0},
        {2, 7, 4, 4},
        {4, 5, 2, 6, 5}
    };

    assert(IsTriangle(triangle));
    assert(MaximumTrianglePath(triangle) == 30);
    assert(MaximumTrianglePathCompact(triangle) == 30);
    assert((RestoreMaximumTrianglePath(triangle) == std::vector<int>{7, 3, 8, 7, 5}));

    assert(MaximumTrianglePath({}) == 0);
    assert(MaximumTrianglePath({{-5}}) == -5);
    assert(MaximumTrianglePath({{-1}, {-2, -3}}) == -3);
    assert(!IsTriangle({{1}, {2}}));
}
```

한 칸짜리 삼각형과 음수 삼각형은 초기값 실수를 확인하기 좋다. 위에서 아래로 계산하는 구현과 아래에서 위로 계산하는 구현의 결과를 여러 입력에서 비교하면 상태 전이와 경계 처리도 함께 검증할 수 있다.
