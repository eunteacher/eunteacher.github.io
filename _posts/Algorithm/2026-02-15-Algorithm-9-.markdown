# [Algorithm] 그래프(Graph)의 정의와 표현 방식

## 1. 소스 코드 (Source Code)

### 1.1 그래프의 개념과 구현
그래프는 정점(Vertex)과 간선(Edge)으로 이루어진 자료구조로, 현실 세계의 연결 관계(지도, 소셜 네트워크 등)를 표현하는 데 사용
주로 **인접 리스트(Adjacency List)**와 **인접 행렬(Adjacency Matrix)** 두 가지 방식으로 구현

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 1. 포인터 기반 연결 (Pointer-based Implementation)
// 트리 구조와 유사하게 노드가 직접 다음 노드의 주소를 가리키는 방식
void CreateGraph_Pointer()
{
    struct Vertex
    {
        vector<Vertex*> Edges; // 간선 목록 (연결된 정점들의 포인터)
    };

    vector<Vertex> v;
    v.resize(6);

    // 정점 간 연결 (Edge 생성)
    v[0].Edges.push_back(&v[1]);
    v[0].Edges.push_back(&v[3]);
    v[1].Edges.push_back(&v[0]);
    v[1].Edges.push_back(&v[2]);
    v[1].Edges.push_back(&v[3]);
    v[3].Edges.push_back(&v[4]);
    v[5].Edges.push_back(&v[4]);

    // 연결 확인 (Connection Check): 0번 -> 3번 연결 여부
    bool bConnected = false;
    // 연결된 모든 간선을 순회해야 하므로 O(Edges) 시간 소요
    for (Vertex* edge : v[0].Edges)
    {
        if (edge == &v[3])
        {
            bConnected = true;
            break;
        }
    }
}

// 2. 인접 리스트 (Adjacency List)
// 가장 일반적인 그래프 표현 방식
// vector<vector<int>>를 사용하여 각 정점에 연결된 '상대 정점의 인덱스'를 저장
void CreateGraph_AdjacencyList()
{
    // 정점의 개수 설정
    const int VertexCount = 6;

    // Adjacent[n] -> n번째 정점과 연결된 정점들의 목록
    vector<vector<int>> Adjacent(VertexCount);

    // 간선 정보 입력
    Adjacent[0] = { 1, 3 };
    Adjacent[1] = { 0, 2, 3 };
    Adjacent[3] = { 4 };
    Adjacent[5] = { 4 };

    // [특징]
    // 지하철 노선도처럼 희소 그래프(Sparse Graph) 표현에 유리함
    // 메모리 사용량: O(V + E) (정점 + 간선 개수만큼만 사용)

    // 연결 확인: 0번 -> 3번 연결 여부
    bool bConnected = false;
    for (int vertex : Adjacent[0])
    {
        if (vertex == 3)
        {
            bConnected = true;
            break;
        }
    }

    // STL 활용 버전 (std::find)
    vector<int>& adj = Adjacent[0];
    bool bConnected2 = (std::find(adj.begin(), adj.end(), 3) != adj.end());
}

// 3. 인접 행렬 (Adjacency Matrix)
// 2차원 배열을 사용하여 정점 간의 연결 관계를 O(1)로 확인하는 방식
void CreateGraph_AdjacencyMatrix()
{
    // [Visualization]
    // [X][O][X][O][X][X]  <- 0번 정점 연결 상태
    // [O][X][O][O][X][X]  <- 1번 정점 연결 상태
    // ...

    // 읽는 방법: Adjacent[From][To]
    // 값이 true면 연결됨, false면 연결 안 됨
    vector<vector<bool>> Adjacent(6, vector<bool>(6, false));

    Adjacent[0][1] = true;
    Adjacent[0][3] = true;
    Adjacent[1][0] = true;
    Adjacent[1][2] = true;
    Adjacent[1][3] = true;
    Adjacent[3][4] = true;
    Adjacent[5][4] = true;

    // [특징]
    // 페이스북 친구 관계처럼 밀집 그래프(Dense Graph) 표현에 유리함.
    // 메모리 소모가 큼 O(V^2), 하지만 접근 속도는 가장 빠름 O(1).

    // 연결 확인: 0번 -> 3번 (즉시 확인 가능)
    bool bConnected = Adjacent[0][3];

    // [응용] 가중치 그래프 (Weighted Graph)
    // 연결 여부(bool) 대신 가중치(int)를 저장.
    // 연결되지 않은 경우 -1 혹은 무한대(INF)로 표현.
    vector<vector<int>> WeightedAdj =
    {
        // 0   1   2   3   4   5
        { -1, 15, -1, 35, -1, -1 }, // Node 0
        { 15, -1, +5, 10, -1, -1 }, // Node 1
        { -1, -1, -1, -1, -1, -1 }, // Node 2
        { -1, -1, -1, -1, +5, -1 }, // Node 3
        { -1, -1, -1, -1, -1, -1 }, // Node 4
        { -1, -1, -1, -1, +5, -1 }, // Node 5
    };
}

int main()
{
    CreateGraph_Pointer();
    CreateGraph_AdjacencyList();
    CreateGraph_AdjacencyMatrix();
}
```

## 2. 이론 정리 (Study Notes)

### 그래프(Graph)의 기본 요소
* **정점 (Vertex/Node)**: 데이터를 담고 있는 객체임 (위치, 사람, 역 등)
* **간선 (Edge/Link)**: 정점들을 연결하는 데 사용되는 선임 (관계, 경로 등)
* **차수 (Degree)**: 한 정점에 연결된 간선의 개수를 의미함



### 그래프의 종류
* **무방향 그래프 (Undirected Graph)**: 간선에 방향이 없어 $A-B$가 $A \to B$이자 $B \to A$와 같음
* **방향 그래프 (Directed Graph)**: 일방통행 도로망처럼 간선에 방향이 존재함
* **가중치 그래프 (Weighted Graph)**: 지하철 노선도처럼 간선에 비용이나 거리 값이 할당됨

### 표현 방식 비교: 인접 리스트 vs 인접 행렬

| 구분 | 인접 리스트 (Adjacency List)| 인접 행렬 (Adjacency Matrix)|
| :--- | :--- | :--- |
| **구조** | `vector<vector<int>>` | `bool Arr[N][N]` (2차원 배열) |
| **공간 복잡도** | $O(V + E)$ (정점 + 간선 개수) | $O(V^2)$ (정점의 제곱) |
| **접근 속도** | $O(Degree(V))$ (연결된 간선 수만큼 탐색)  | $O(1)$ (인덱스로 즉시 접근)  |
| **적합한 상황** | **희소 그래프 (Sparse Graph)**<br>(예: 지하철 노선도, 도로망) | **밀집 그래프 (Dense Graph)**<br>(예: SNS 친구 관계, 격자 맵) |
| **장점** | 메모리를 효율적으로 사용함  | 두 정점의 연결 여부를 가장 빠르게 확인함  |
| **단점** | 연결 여부를 확인하려면 순회해야 함  | 간선이 적어도 무조건 $N \times N$ 메모리를 차지함  |

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항
* **메모리와 속도의 트레이드오프**: 인접 행렬은 접근 속도가 $O(1)$로 매우 빠르지만 메모리 소모가 심하고, 인접 리스트는 메모리는 절약되나 연결 확인 속도가 상대적으로 느림
* **현업에서의 선택**: 실제 게임 서버나 알고리즘 문제에서는 정점($V$)에 비해 간선($E$)이 적은 경우가 많아 주로 **인접 리스트** 방식을 채택
* **메모리 초과 주의**: 정점이 10만 개일 때 인접 행렬($100,000^2$)을 사용하면 메모리 초과가 발생하므로 설계 시 데이터 규모를 반드시 고려

### Tip
* **가중치 그래프 구현**: 인접 리스트 사용 시 `vector<vector<pair<int, int>>>` 형태를 활용하여 `{도착 정점, 가중치}`를 쌍으로 저장
* **STL 활용 최적화**: `std::find`를 쓰면 코드는 간결해지지만 내부적으로는 여전히 $O(N)$ 반복문이 작동하므로 빈번한 호출 시 성능을 체크해야 함
