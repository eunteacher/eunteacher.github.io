# [C++] 조건식은 어떻게 참과 거짓을 만드는가

## 조건을 만드는 비교 연산

변수 간의 값을 비교(`Comparison`)하거나 논리적인 조건(`Logical`)을 판단하는 연산자 활용 예제

```cpp
#include <iostream>
using namespace std;

// 전역 변수 선언 및 초기화
int a = 1;      // 정수형 변수 a 할당 및 1 대입
int b = 2;      // 정수형 변수 b 할당 및 2 대입

// 결과 저장을 위한 bool 변수들 (True/False)
bool bIsSame;
bool bIsDifferent;
bool bIsGreater;
bool bIsSmaller;
bool bTest;

// 게임 로직 예시를 위한 변수
bool bIsInvincible = true; // 무적 상태 여부
int hp = 100;              // 체력

int main()
{
    // 1. 비교 연산 (Comparison Operators)
    // 결과값은 항상 참(True, 1) 또는 거짓(False, 0)으로 반환됨

    // Equal (==): 값이 같은가?
    bIsSame = (a == b);

    // Not Equal (!=): 값이 다른가?
    bIsDifferent = (a != b);

    // Greater (>): a가 b보다 큰가?
    bIsGreater = (a > b);

    // Greater or Equal (>=): a가 b보다 크거나 같은가?
    bIsGreater = (a >= b);

    // Less (<): a가 b보다 작은가?
    bIsSmaller = (a < b);

    // Less or Equal (<=): a가 b보다 작거나 같은가?
    bIsSmaller = (a <= b);


    // 2. 논리 연산 (Logical Operators)
    // 여러 조건을 조합하여 복합적인 판단을 수행함

    // NOT (!): 논리 부정 (0이면 1, 0이 아니면 0)
    bTest = !bIsSame;

    // AND (&&): 논리 곱 (둘 다 참이어야 참)
    // 예: 체력이 0 이하이고, 무적 상태가 아닐 때 -> 사망 처리
    bTest = (hp <= 0 && bIsInvincible == false);

    // OR (||): 논리 합 (둘 중 하나라도 참이면 참)
    // 예: 체력이 남아있거나, 무적 상태일 때 -> 생존
    bTest = (hp > 0 || bIsInvincible == true);

    return 0;
}
```

## 비교 결과와 논리 연산의 규칙

### 2.1 데이터의 할당과 자료형 (`bool`)
* **할당 (Allocation)**: 메모리 공간을 확보하고 이름(변수명)을 붙이는 행위
* **`bool` 자료형**: `true`와 `false`를 저장하며 비교 및 논리 연산의 결과로 사용한다. 크기는 구현에 따라 정해지므로 항상 1바이트라고 가정하지 않는다.

### 2.2 비교 연산자 (Comparison Operators)
두 데이터를 비교하여 그 결과를 `bool` 값으로 반환하는 연산자

| 연산자 | 명칭 | 설명 | 수식 표현 |
| :---: | :--- | :--- | :---: |
| `==` | Equal | 두 값이 같으면 참 | $A = B$ |
| `!=` | Not Equal | 두 값이 다르면 참 | $A \neq B$ |
| `>` | Greater Than | 왼쪽이 크면 참 | $A > B$ |
| `<` | Less Than | 오른쪽이 크면 참 | $A < B$ |
| `>=` | Greater Than or Equal | 왼쪽이 크거나 같으면 참 | $A \ge B$ |
| `<=` | Less Than or Equal | 오른쪽이 크거나 같으면 참 | $A \le B$ |

### 2.3 논리 연산자 (Logical Operators)
참/거짓의 논리값을 조합하여 새로운 논리값을 도출하는 연산자

| 연산자 | 명칭 | 설명 | 진리표 (A, B가 참일 때) |
| :---: | :--- | :--- | :--- |
| `!` | **NOT** | 참이면 거짓, 거짓이면 참으로 반전 | `!True` $\rightarrow$ `False` |
| `&&` | **AND** | 양쪽 모두 참일 때만 참 (교집합) | `True && True` $\rightarrow$ `True` |
| `||` | **OR** | 둘 중 하나라도 참이면 참 (합집합) | `True || False` $\rightarrow$ `True` |

## 실전에서 조건식을 읽는 방법

### 핵심 요약 및 주의사항
* **대입 연산자 실수**: 프로그래밍 입문 시 가장 많이 하는 실수는 비교 연산자 `==` 대신 대입 연산자 `=`를 사용
  * `if (a = b)`: b의 값을 a에 대입하고, 그 결과값으로 조건을 판단해버리는 버그 발생
* **연산자 우선순위**: 복잡한 조건식에서는 `!` > `&&` > `||` 순으로 연산됨. 헷갈릴 경우 괄호 `()`를 사용하여 의도를 명확히 하는 것이 좋음

### Tip
* **단축 평가 (Short-Circuit Evaluation)**:
  * `A && B`: A가 거짓이면 B는 검사하지 않고 바로 거짓 처리 (성능 이점)
  * `A || B`: A가 참이면 B는 검사하지 않고 바로 참 처리
  * **활용**: `if (ptr != nullptr && ptr->hp > 0)` 처럼 포인터가 유효한지 먼저 검사하는 안전장치로 자주 사용
* **네이밍 컨벤션**: `bool` 변수는 `b` 접두사나 `is`, `has` 등으로 시작하게 지으면 가독성이 좋아짐 (예: `bIsReady`, `isFinished`)

### 단축 평가는 안전 장치이기도 하다

`&&`는 왼쪽이 거짓이면 오른쪽을 평가하지 않고, `||`는 왼쪽이 참이면 오른쪽을 평가하지 않는다. 따라서 검사 순서 자체가 의미를 가진다.

```cpp
if (player != nullptr && player->hp > 0)
{
    // player가 유효할 때만 역참조한다.
}
```

단축 평가에 중요한 상태 변경을 숨기면 흐름을 추적하기 어려워진다. 오른쪽 표현식은 가능하면 “검사” 역할에 집중시키는 편이 좋다.

## 마무리

조건식은 단순히 연산자를 이어 붙이는 문장이 아니다. 상호 배타적인 조건인지, 검사 순서가 안전한지, 부동소수점의 동등 비교가 의도에 맞는지까지 확인해야 한다. 다음 글에서는 값을 바꾸지 않겠다는 약속인 `const`와 객체의 저장 기간을 분리해 살펴본다.
