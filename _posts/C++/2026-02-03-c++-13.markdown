# [C++] 이중 반복문(Nested Loop)을 활용한 별 찍기와 구구단

## 1. 소스 코드 (Source Code)

사용자로부터 정수 $N$을 입력받아 다양한 형태로 별(`*`)을 출력하고, 이중 `for`문을 이용해 구구단을 출력하는 실습 예제

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 입력받을 변수 선언
    int Input;
    cout << "정수 입력 : ";

    // [std::cin]: 키보드 입력을 받아서 변수에 저장 (>> 연산자 사용)
    cin >> Input;

    // [1] N * N 정사각형 별 찍기
    // i: 행(Row) / j: 열(Col)
    cout << "--- 1번: 정사각형 ---" << endl;
    for (int i = 0; i < Input; i++)
    {
        for (int j = 0; j < Input; j++)
        {
            cout << "*";
        }
        cout << endl; // 한 행이 끝나면 줄바꿈
    }

    // [2] 직각 삼각형 별 찍기 (증가형)
    // 1번째 줄 1개, 2번째 줄 2개 ... N번째 줄 N개
    cout << "\n--- 2번: 삼각형 (증가) ---" << endl;
    for (int i = 0; i < Input; i++)
    {
        // 내부 루프의 조건식이 외부 루프 변수(i)에 의존함
        // i=0일 때 j는 0~0 (1회)
        // i=1일 때 j는 0~1 (2회)
        for (int j = 0; j < i + 1; j++)
        {
            cout << "*";
        }

        cout << endl;
    }

    // [3] 역직각 삼각형 별 찍기 (감소형)
    // N번째 줄 N개 ... 2번째 줄 2개, 1번째 줄 1개
    cout << "\n--- 3번: 삼각형 (감소) ---" << endl;
    // 초기값을 Input으로 잡고 0보다 클 때까지 감소시킴
    for (int i = Input; i > 0; i--)
    {
        for (int j = i; j > 0; j--)
        {
            cout << "*";
        }

        cout << endl;
    }

    // [4] 구구단 (Multiplication Table)
    // 2단부터 9단까지 출력
    cout << "\n--- 4번: 구구단 ---" << endl;
    for (int i = 2; i <= 9; i++) // 단 (2 ~ 9)
    {
        cout << "[" << i << "단]" << endl;
        for (int j = 1; j <= 9; j++) // 곱해지는 수 (1 ~ 9)
        {
            cout << i << " * " << j << " = " << i * j << endl;
        }
        cout << endl; // 단 사이 줄바꿈
    }
}
```

## 2. 이론 정리 (Study Notes)

### 2.1 표준 입력 (`std::cin`)
* **역할**: 키보드 입력 스트림(Standard Input Stream)을 통해 데이터를 받음
* **추출 연산자 (`>>`)**: 스트림에서 데이터를 추출하여 오른쪽 변수에 저장함. 공백(Space)이나 엔터(Enter)를 기준으로 입력을 구분

### 2.2 이중 반복문 (Nested Loop)
반복문 안에 또 다른 반복문이 들어있는 구조. 2차원 데이터를 처리할 때 필수

* **동작 원리**:
  1.  외부 루프(Outer Loop)가 1회 실행될 때,
  2.  내부 루프(Inner Loop)는 자신의 조건이 끝날 때까지 **전체 순회**함
  3.  내부 루프 종료 후, 외부 루프가 다음 단계로 진행됨
* **시간 복잡도**: 외부 루프가 $N$번, 내부 루프가 $M$번 돌 경우 총 수행 횟수는 $N \times M$이 됨 ($O(N^2)$)

### 2.3 별 찍기 알고리즘의 핵심
행(`i`)과 열(`j`)의 관계(Relation)를 수식으로 정의하는 것이 관건

| 형태 | 외부 루프 (`i`) | 내부 루프 (`j`) 조건 | 비고 |
| :--- | :--- | :--- | :--- |
| **정사각형** | $0 \rightarrow N$ | $j < N$ | 항상 $N$번 반복 |
| **삼각형(증가)** | $0 \rightarrow N$ | $j < i + 1$ | $i$가 커질수록 반복 횟수 증가 |
| **삼각형(감소)** | $N \rightarrow 0$ | $j < i$ | $i$가 작아질수록 반복 횟수 감소 |

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항
* **인덱스 관리**: 반복문에서 `0`부터 시작할지(`i=0`), `1`부터 시작할지(`i=1`)에 따라 종료 조건(` < ` vs ` <= `)이 달라지므로 주의해야 함 (**Off-by-one Error**)
* **변수 범위**: 내부 루프(`j`)에서 외부 루프 변수(`i`)를 사용할 때, 그 관계를 정확히 파악해야 원하는 모양의 패턴을 만들 수 있음
* **무한 루프**: 감소형 루프(`i--`) 작성 시 조건을 `i > 0` 등으로 명확히 하지 않으면 언더플로우로 인한 무한 루프에 빠질 위험이 있음

### Tip
* **디버깅**: 별이 이상하게 찍힌다면, 종이에 $N=3$ 정도의 작은 수를 대입하여 `i`와 `j`의 변화를 **표(Trace Table)**로 그려보는 것이 가장 빠른 해결책임
* **성능**: `cout << endl`은 버퍼를 비우는(Flush) 작업이 포함되어 느림. 대량의 출력 시에는 `\n`을 사용하는 것이 성능상 유리함
