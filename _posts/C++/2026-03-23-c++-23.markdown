# [C++] 포인터에 1을 더한다는 것의 정확한 의미

포인터를 다루기 위한 4가지 핵심 연산자(&, *, +, ->)의 동작 방식과 자료형 기반의 메모리 이동 원리를 분석함

## 주소·역참조·멤버 접근

```cpp
#include <iostream>
using namespace std;

// 간접 멤버 연산자 테스트용 구조체
struct Player
{
    int hp;      // 시작 주소 오프셋 +0
    int damage;  // 시작 주소 오프셋 +4 (int 4바이트 기준)
};

int main()
{
    // 1) 주소 연산자 (&)
    // 변수가 할당된 메모리의 시작 주소를 반환함
    int number = 1;

    // 포인터 변수 선언 시 대상 변수의 타입에 맞게 선언해야 메모리 오염을 방지할 수 있음
    int* ptr = &number;

    // 2) 산술 연산자 (+, -, ++, --)
    // 일반 변수의 산술 연산은 수치값을 지정된 만큼 직접 증감시킴
    number = number + 1;
    number++;
    ++number;
    number += 1;

    // 포인터의 산술 연산은 현재 가리키는 대상 '타입의 크기'만큼 주소를 이동함
    // int형(4바이트) 포인터에 1을 더하면 실제 메모리 주소는 4바이트 증가함
    ptr = ptr + 1;
    ptr++;
    ++ptr;
    ptr += 1;

    // 3) 간접 연산자 (역참조, *)
    // 해당 주소로 직접 찾아가서 메모리 공간에 값을 쓰거나 읽어옴
    number = 3;
    *ptr = 3;

    // 4) 간접 멤버 연산자 (->)
    Player player;
    player.hp = 100;
    player.damage = 10;

    // 구조체의 시작 주소를 포인터에 할당함
    Player* playerPtr = &player;

    // 역참조 연산자(*)와 멤버 접근 연산자(.)를 조합하여 사용할 수 있으나 괄호가 강제됨
    (*playerPtr).hp = 200;
    (*playerPtr).damage = 20;

    // 간접 멤버 연산자(->)를 사용하면 포인터를 통해 구조체 멤버에 더 직관적으로 접근 가능함
    playerPtr->hp = 300;
    playerPtr->damage = 30;

    return 0;
}
```

## 포인터 산술이 성립하는 범위

### 포인터 제어 핵심 연산자 요약

| 연산자 이름 | 기호 | 기능 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| **주소 (Address-of)** | `&` | 변수의 메모리 시작 주소를 추출함 | 대상 변수의 앞에 부착하여 사용 |
| **간접 / 역참조 (Dereference)** | `*` | 저장된 주소 번지로 직접 찾아가서 데이터를 읽거나 씀 | 포인터가 유효한 메모리를 가리킬 때만 사용 |
| **산술 (Arithmetic)** | `+`, `-` | 데이터 타입의 크기 단위로 메모리 주소를 이동함 | 배열 순회 등 연속된 메모리 접근에 활용 |
| **간접 멤버 (Arrow)** | `->` | 포인터 변수를 통해 구조체나 클래스의 내부 멤버에 직접 접근함 | `(*ptr).member`와 완벽히 동일한 기능 |

### 포인터 산술 연산(Arithmetic) 메모리 이동 수식

포인터에 정수값 $N$을 더하거나 뺄 때, 실제 메모리 주소가 이동하는 변위량은 다음과 같은 수식으로 계산됨

$$\text{New Address} = \text{Current Address} + (N \times \text{sizeof}(\text{Type}))$$

* $\text{sizeof}(\text{Type})$: 포인터가 가리키는 자료형의 크기(Byte)를 의미함
* 예시: `int*` (4바이트) 타입 포인터에 $+1$을 연산하면 실제 메모리 주소는 $+4$번지 이동함

## 배열 밖 주소는 역참조하지 않는다

### 핵심 요약 및 주의사항

* **타입 의존적 산술 연산:** 포인터의 산술 연산은 단순한 덧셈이 아니라 '다음 데이터가 있는 위치'로의 이동을 의미
* **메모리 이탈 주의:** 포인터 산술 연산을 통해 이동할 때, 할당된 메모리 영역(배열 크기 등)을 벗어나면 정의되지 않은 동작(Undefined Behavior)이나 런타임 에러가 발생하므로 경계 검사가 필수
* **연산자 우선순위:** `*ptr.member`로 작성하면 `.` 연산자가 `*`보다 우선순위가 높아 에러가 발생하므로, 반드시 `(*ptr).member`로 묶거나 직관적인 `ptr->member`를 사용

### Tip

* **포인터 크기:** 흔한 환경에서는 데이터 포인터 크기가 같지만 C++이 모든 종류의 포인터 크기를 동일하게 보장하지는 않는다. 필요하면 `sizeof`로 대상 구현을 확인한다.
* **배열과의 관계:** 배열 식은 대부분의 표현식에서 첫 요소를 가리키는 포인터로 변환된다. `sizeof`, 주소 연산자, 참조 바인딩 등 변환되지 않는 문맥도 있다.
* **초기화 습관:** 가리킬 주소가 명확하지 않은 포인터를 연산하거나 역참조하면 치명적인 오류가 발생하므로, 선언 시점에는 가급적 `nullptr`로 초기화하는 습관이 필요

포인터 산술은 같은 배열 객체의 요소와 마지막 요소 바로 다음 위치(one-past-the-end)까지만 의미가 있다. 마지막 다음 포인터는 반복 종료 비교에는 사용할 수 있지만 역참조할 수 없다. 서로 무관한 객체를 가리키는 포인터의 뺄셈이나 순서 비교도 일반적으로 유효하지 않다.

## 마무리

포인터 산술은 임의의 메모리 주소 계산 기능이 아니라 배열 순회를 위한 제한된 규칙이다. 시작과 끝을 함께 전달하거나 `std::span`을 사용하면 포인터 하나만 전달할 때 잃어버리는 범위 정보를 보존할 수 있다.
