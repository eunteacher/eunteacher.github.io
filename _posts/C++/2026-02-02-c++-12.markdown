# [C++] 반복의 시작·계속·종료 조건을 한눈에 보기

특정 조건이 만족될 때까지 코드를 반복 실행하는 **반복문(Loop)**의 3가지 형태(`while`, `do-while`, `for`)와, 흐름을 끊거나 건너뛰는 제어문(`break`, `continue`)에 대해 정리

---

## 세 반복문의 실행 순서

`while`, `do-while`, `for` 반복문의 기본 문법과 `break`, `continue`를 활용한 전투 로직 및 홀수 출력 예제

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 1. While 문
    // - 조건식이 참(True)인 동안 계속 반복
    // - 반복 횟수가 명확하지 않을 때 주로 사용 (예: 게임 종료 시까지)

    int count = 0;

    while (count < 5)
    {
        cout << "While Loop: " << count << endl;
        count++; // 증감식이 없으면 무한 루프(Infinite Loop)에 빠짐
    }
    cout << endl;

    // 2. Do-While 문
    // - 명령문을 먼저 실행하고 나중에 조건을 검사
    // - 조건이 거짓이어도 '최소 1회' 실행을 보장함

    do
    {
        cout << "Do-While: 실행됨" << endl;
    } while (false); // 조건이 거짓이지만 1번은 출력됨

    cout << endl;

    // 3. For 문
    // - [초기식; 조건식; 제어식] 구조
    // - 반복 횟수가 명확할 때 주로 사용 (예: 배열 순회, N번 반복)

    for (int i = 0; i < 5; i++)
    {
        cout << "For Loop: " << i << endl;
    }
    cout << endl;

    // 4. Break와 Continue 활용 (전투 시뮬레이션)

    int round = 1;
    int hp = 100;
    int damage = 10;

    // 무한 루프 (Infinite Loop): 조건이 항상 true
    while (true)
    {
        hp -= damage;

        // 체력 보정 (음수 방지)
        if (hp < 0)
            hp = 0;

        cout << "Round " << round << " | 몬스터 체력: " << hp << endl;

        // [Break]: 반복문을 즉시 탈출
        if (hp == 0)
        {
            cout << "몬스터 처치 완료!" << endl;
            break;
        }

        if (round == 5)
        {
            cout << "제한 라운드 종료 (Time Over)" << endl;
            break;
        }

        round++;
    }
    cout << endl;

    // 5. Continue 활용 (홀수만 출력하기)
    // 1 ~ 10 사이의 숫자 중 짝수는 건너뜀

    cout << "[홀수 출력]" << endl;
    for (int i = 1; i <= 10; i++)
    {
        bool bIsEven = (i % 2 == 0);

        // [Continue]: 아래 코드를 실행하지 않고 증감식(i++)으로 점프
        if (bIsEven)
        {
            continue;
        }

        cout << i << " ";
    }
    cout << endl;

    return 0;
}
```

## 반복 조건을 어디에 둘 것인가

### 2.1 반복문의 종류 비교
프로그램의 흐름을 제어하는 반복문은 크게 세 가지로 나뉘며, 각각의 사용 목적이 다름

| 종류 | 문법 구조 | 검사 시점 | 최소 실행 | 주 사용처 |
| :---: | :--- | :---: | :---: | :--- |
| **while** | `while(조건) { ... }` | 선(先) 비교 | 0회 | 반복 횟수를 모를 때, 특정 상태가 될 때까지 |
| **do-while** | `do { ... } while(조건);` | 후(後) 비교 | **1회** | 사용자 입력 대기, 메뉴 선택 등 |
| **for** | `for(초기; 조건; 증감) { ... }` | 선(先) 비교 | 0회 | 반복 횟수가 정해져 있을 때, 배열 인덱스 접근 |

### 2.2 제어 흐름 키워드
* **break**: 반복문을 즉시 **종료**하고 블록 밖으로 빠져나감
  * 주로 무한 루프의 종료 조건이나 `switch` 문에서 사용
* **continue**: 현재 회차의 남은 코드를 무시하고 **다음 반복**으로 넘어감
  * `while` 문에서는 **조건식**으로 이동
  * `for` 문에서는 **증감식(제어식)**으로 이동

### 2.3 나머지 연산자 활용 (%)
짝수와 홀수를 구분하거나 특정 주기를 구할 때 나머지 연산이 핵심적으로 사용됨

$$
i \pmod 2 =
\begin{cases}
0 & \text{(짝수, Even)} \\
1 & \text{(홀수, Odd)}
\end{cases}
$$

## 종료 조건부터 검토하기

### 핵심 요약 및 주의사항
* **무한 루프의 검토**: `while(true)` 자체가 잘못은 아니다. 이벤트 루프처럼 의도적으로 계속 실행할 수도 있다. 유한 작업이라면 종료 조건이 실제로 도달 가능한지 확인한다.
* **증감식 누락**: `while` 문을 쓸 때 `count++`와 같은 증감식을 빼먹어서 의도치 않은 무한 루프에 빠지는 실수가 잦음
* **do-while의 세미콜론**: `do-while` 문은 유일하게 끝에 세미콜론(`;`)을 붙여야 함 (`while(조건);`)

### Tip
* **가독성**: 반복 횟수가 명확하다면 `while`보다는 `for` 문을 사용하는 것이 초기화/조건/증감이 한 줄에 보여 가독성이 좋음
* **흐름 단순화**: `continue`로 처리할 필요가 없는 경우를 먼저 건너뛰면 중첩을 줄일 수 있다. 다만 반복문의 상태 변경을 건너뛰지 않는지 확인해야 한다.
  * **Bad**: `if (정상) { 실행 }`
  * **Good**: `if (비정상) continue; 실행`

`for`에서 `continue`는 증감식으로 이동하지만, `while`에서는 조건 검사로 바로 이동한다. 다음 코드는 `continue` 때문에 `count++`에 도달하지 못해 끝나지 않는다.

```cpp
while (count < 10)
{
    if (count == 3)
        continue; // count가 계속 3

    ++count;
}
```
