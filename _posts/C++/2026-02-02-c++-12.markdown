앞에서는 조건에 따라 실행 경로를 선택하는 `if`와 `switch`를 살펴봤다. 같은 작업을 여러 번 수행하려면 분기문만으로는 부족하다. 반복이 끝날 때까지 다시 이전 위치로 돌아가는 흐름이 필요하다.

반복문(Loop)은 코드를 단순히 여러 번 복사해서 실행하는 문법이 아니다. 반복을 시작할 상태, 계속할 조건, 한 회차에서 수행할 작업, 다음 회차를 위한 상태 변경이 함께 구성된 제어 흐름이다.

## 반복문은 네 요소로 읽는다

일반적인 반복문은 다음 네 요소를 가진다.

```text
1. 초기 상태
2. 계속 조건
3. 반복할 작업
4. 상태 변경
```

0부터 4까지 출력하는 반복을 이 구조에 맞춰 보면 다음과 같다.

```cpp
int count = 0;       // 초기 상태

while (count < 5)    // 계속 조건
{
    std::cout << count << '\n'; // 반복할 작업
    ++count;                   // 상태 변경
}
```

실행 흐름은 다음과 같다.

```text
count = 0
    │
    ▼
count < 5 검사 ◄────────────┐
    │                       │
    ├── true                │
    │    출력               │
    │    ++count ───────────┘
    │
    └── false → 반복 종료
```

반복문이 끝나지 않는다면 네 요소 중 하나를 확인한다.

- 초기 상태가 잘못됐는가?
- 조건이 계속 `true`가 되는가?
- 상태 변경이 실행되지 않는 경로가 있는가?
- 종료 조건에 실제로 도달할 수 있는가?

문법보다 이 흐름을 먼저 보면 `while`, `do-while`, `for`의 차이도 쉽게 구분할 수 있다.

## `while`은 작업 전에 조건을 검사한다

`while`은 반복 본문을 실행하기 전에 조건을 검사한다.

```cpp
int count = 0;

while (count < 5)
{
    std::cout << count << '\n';
    ++count;
}
```

조건이 처음부터 `false`라면 본문은 한 번도 실행되지 않는다.

```cpp
int count = 10;

while (count < 5)
{
    std::cout << count << '\n';
    ++count;
}
```

`10 < 5`는 처음부터 `false`이므로 출력은 없다.

`while`은 반복 횟수보다 **현재 상태가 조건을 만족하는 동안 계속한다**는 표현에 적합하다.

```cpp
while (monsterHp > 0)
{
    monsterHp -= damage;
}
```

몬스터가 몇 번의 공격 뒤 죽을지는 `monsterHp`와 `damage`에 따라 달라진다. 반복 횟수를 직접 세기보다 상태 조건을 중심으로 읽는 코드다.

## 조건을 검사하는 시점의 값을 추적한다

다음 코드가 어떤 값을 출력하는지 순서대로 추적해 보자.

```cpp
int value = 1;

while (value < 10)
{
    std::cout << value << '\n';
    value *= 2;
}
```

| 조건 검사 시점의 `value` | `value < 10` | 실행 결과 |
| :---: | :---: | :--- |
| 1 | true | 1 출력 후 2 |
| 2 | true | 2 출력 후 4 |
| 4 | true | 4 출력 후 8 |
| 8 | true | 8 출력 후 16 |
| 16 | false | 반복 종료 |

출력되는 마지막 값은 8이다. `value`가 16이 된 뒤 조건을 다시 검사하지만 본문에 들어가지 않으므로 16은 출력되지 않는다.

반복문을 읽을 때는 본문 안의 값뿐 아니라 **다음 조건 검사 시점에 어떤 값이 되는지** 확인해야 한다.

## `do-while`은 작업을 먼저 한 번 실행한다

`do-while`은 본문을 먼저 실행한 뒤 계속할 조건을 검사한다.

```cpp
int count = 10;

do
{
    std::cout << count << '\n';
    ++count;
} while (count < 5);
```

처음부터 `count < 5`가 거짓이지만 10이 한 번 출력된다.

```text
본문 실행
   │
   ▼
조건 검사
   │
   ├── true  → 본문으로 돌아감
   └── false → 반복 종료
```

본문이 최소 한 번은 실행돼야 하는 메뉴나 입력 처리에서 사용할 수 있다.

```cpp
int menu = 0;

do
{
    std::cout << "1. Start\n";
    std::cout << "2. Exit\n";
    std::cin >> menu;
} while (menu != 1 && menu != 2);
```

메뉴를 먼저 보여주고 입력을 받은 뒤 유효한 값인지 검사한다.

`do-while`은 마지막 조건식 뒤에 세미콜론이 필요하다.

```cpp
} while (condition);
```

일반 `while`문과 생김새가 달라 빠뜨리기 쉬운 부분이다.

## `for`는 반복 제어 요소를 한곳에 모은다

`for`문의 괄호에는 초기화문, 조건식, 증감식이 들어간다.

```cpp
for (int i = 0; i < 5; ++i)
{
    std::cout << i << '\n';
}
```

각 부분의 실행 순서는 다음과 같다.

```text
초기화문 int i = 0
        │
        ▼
조건식 i < 5 ◄──────────────┐
        │                    │
        ├── true             │
        │    본문 실행       │
        │    증감식 ++i ─────┘
        │
        └── false → 반복 종료
```

초기화문은 반복 전체에서 한 번만 실행된다. 조건식은 매 회차 본문 전에 검사하고, 증감식은 본문이 정상적으로 끝난 뒤 실행된다.

실행 순서를 값으로 펼치면 다음과 같다.

| 단계 | `i` | 동작 |
| :---: | :---: | :--- |
| 초기화 | 0 | `int i = 0` |
| 조건 | 0 | `0 < 5`, true |
| 본문 | 0 | 0 출력 |
| 증감 | 1 | `++i` |
| 조건 | 1 | `1 < 5`, true |
| ... | ... | ... |
| 조건 | 5 | `5 < 5`, false |

따라서 0, 1, 2, 3, 4가 출력되고 `i`가 5일 때 반복이 끝난다.

## `for`문의 변수는 반복문 밖에서 보이지 않는다

초기화문에 선언한 변수의 스코프는 `for`문 전체다.

```cpp
for (int i = 0; i < 5; ++i)
{
    std::cout << i << '\n';
}

// std::cout << i << '\n'; // for문 밖에서는 사용할 수 없음
```

반복이 끝난 뒤 인덱스를 사용할 필요가 없다면 이처럼 스코프를 반복문 안으로 제한한다.

반복 종료 후 값이 필요하다면 바깥에 선언한다.

```cpp
int i = 0;

for (; i < 5; ++i)
{
    std::cout << i << '\n';
}

std::cout << "Final index: " << i << '\n';
```

초기화문을 비운 경우에도 첫 번째 세미콜론은 남겨야 한다.

## `for`의 세 부분은 생략할 수 있다

`for`문의 초기화문, 조건식, 증감식은 각각 생략할 수 있다.

```cpp
int count = 0;

for (; count < 5;)
{
    std::cout << count << '\n';
    ++count;
}
```

세 부분을 모두 생략하면 조건이 항상 참인 반복이 된다.

```cpp
for (;;)
{
    // 반복 작업
}
```

문법적으로는 유효하지만 반복을 끝내려면 본문 안의 `break`, `return`, 예외, 또는 프로그램 외부의 종료 조건이 필요하다.

빈 부분이 많아져 `for`의 구조가 오히려 의미를 숨긴다면 `while`을 사용하는 편이 자연스럽다.

```cpp
while (isRunning)
{
    Update();
}
```

## `while`과 `for`는 성능보다 표현 방식으로 선택한다

다음 두 반복문은 비슷한 흐름을 표현한다.

```cpp
int count = 0;

while (count < 5)
{
    std::cout << count << '\n';
    ++count;
}
```

```cpp
for (int count = 0; count < 5; ++count)
{
    std::cout << count << '\n';
}
```

반복 횟수를 제어하는 초기값·조건·증감이 하나의 묶음이라면 `for`가 구조를 잘 보여준다. 외부 상태가 바뀔 때까지 반복한다면 `while`이 자연스럽다.

```text
카운터를 중심으로 N번 반복  → for
상태가 유지되는 동안 반복   → while
본문을 먼저 한 번 실행       → do-while
```

이는 절대적인 규칙이 아니라 코드를 읽는 기준이다. 동일한 동작을 표현한다면 어느 문법이 무조건 더 빠르다고 가정할 필요는 없다.

## 반복 횟수는 경계를 먼저 정한다

0부터 시작해 정확히 `count`번 반복하려면 다음 형태를 자주 사용한다.

```cpp
for (int i = 0; i < count; ++i)
{
    std::cout << i << '\n';
}
```

`count`가 5라면 `i`는 0, 1, 2, 3, 4가 된다. 총 다섯 번 실행된다.

1부터 `count`까지 포함해서 출력하려면 시작점과 조건이 달라진다.

```cpp
for (int number = 1; number <= count; ++number)
{
    std::cout << number << '\n';
}
```

두 형태는 모두 다섯 번 반복할 수 있지만 생성하는 값의 범위가 다르다.

```text
0 <= i < count        → 0, 1, 2, 3, 4
1 <= number <= count  → 1, 2, 3, 4, 5
```

`<`와 `<=`를 바꿀 때는 반복 횟수뿐 아니라 인덱스나 출력값의 의미도 함께 확인한다.

## Off-by-one 오류는 경계에서 한 번 더 또는 덜 반복한다

반복 횟수가 의도보다 하나 많거나 적은 오류를 Off-by-one 오류라고 한다.

```cpp
int count = 5;

for (int i = 0; i <= count; ++i)
{
    std::cout << i << '\n';
}
```

0부터 5까지 총 여섯 번 실행된다. 0부터 시작해 다섯 번 반복하려는 목적이었다면 조건은 `i < count`여야 한다.

경계를 검토할 때 다음 값을 직접 적어보면 도움이 된다.

- 첫 번째 반복의 값
- 마지막으로 실행돼야 하는 값
- 반복이 끝나는 첫 번째 값

```text
첫 실행       i = 0
마지막 실행   i = 4
첫 종료       i = 5
```

반복문 본문만 보지 말고 조건이 거짓이 되는 최초의 상태까지 확인한다.

## 감소 반복에서는 부호 없는 타입을 주의한다

부호 없는 정수는 0보다 작아질 수 없다.

```cpp
for (unsigned int i = 5; i >= 0; --i)
{
    std::cout << i << '\n';
}
```

`i >= 0`은 부호 없는 값에서 항상 참이다. `i`가 0인 상태에서 `--i`를 수행하면 해당 타입의 최댓값으로 순환하므로 반복이 끝나지 않는다.

0을 포함한 역순 반복은 감소 전에 0보다 큰지 확인하고, 본문에서 한 단계 앞의 값을 사용할 수 있다.

```cpp
for (unsigned int i = 5; i > 0; --i)
{
    std::cout << i - 1 << '\n';
}
```

`i`가 1일 때 본문에서 0을 출력하고, 증감식에서 `i`를 0으로 만든다. 다음 조건 `i > 0`이 거짓이므로 언더플로 없이 반복을 끝낸다. 다만 출력값과 제어 변수의 값이 하나씩 어긋나는 형태가 낯설다면 부호 있는 타입으로 범위를 표현할 수 있는지 검토하거나, 이후 컨테이너를 배울 때 역방향 반복자를 사용하는 편이 읽기 쉬울 수 있다.

## 반복 변수는 한곳에서 변경한다

`for`문의 증감식에서 제어 변수를 변경하면서 본문에서도 다시 변경하면 반복 횟수를 추적하기 어렵다.

```cpp
for (int i = 0; i < 10; ++i)
{
    if (ShouldSkipNext())
    {
        ++i;
    }

    std::cout << i << '\n';
}
```

조건에 따라 `i`가 한 번 또는 두 번 증가한다. 특별히 다음 항목까지 건너뛰는 알고리즘이라면 의도일 수 있지만, 단순한 반복에서는 제어 변수 변경을 증감식 한곳에 두는 편이 좋다.

여러 단계씩 이동해야 한다면 증감식에서 규칙을 드러낸다.

```cpp
for (int i = 0; i < 10; i += 2)
{
    std::cout << i << '\n'; // 0, 2, 4, 6, 8
}
```

## `break`는 가장 가까운 반복문을 끝낸다

`break`를 실행하면 현재 반복문을 즉시 종료하고 반복문 다음 문장으로 이동한다.

```cpp
for (int i = 0; i < 10; ++i)
{
    if (i == 5)
    {
        break;
    }

    std::cout << i << '\n';
}

std::cout << "Loop end\n";
```

0부터 4까지 출력한 뒤 `i == 5`에서 반복을 종료한다.

```text
i == 5
   │
   ├── false → 출력 후 다음 반복
   └── true  → break → Loop end
```

`break`는 `if`문을 끝내는 키워드가 아니다. `if`가 반복문 안에 있더라도 가장 가까운 반복문이나 `switch`를 빠져나간다.

## 중첩 반복문의 `break`는 안쪽 반복문만 끝낸다

반복문이 중첩돼 있다면 `break`는 가장 가까운 반복문 하나만 종료한다.

```cpp
for (int row = 0; row < 3; ++row)
{
    for (int column = 0; column < 3; ++column)
    {
        if (column == 1)
        {
            break;
        }

        std::cout << row << ", " << column << '\n';
    }
}
```

안쪽 `column` 반복은 매 행에서 1을 만날 때 끝나지만 바깥 `row` 반복은 계속된다.

```text
0, 0
1, 0
2, 0
```

중첩 반복 전체를 종료해야 한다면 결과를 함수로 분리해 `return`하거나, 종료 상태를 바깥 반복 조건에 반영하는 등 의도를 명확히 표현해야 한다. 단순히 `break` 하나로 모든 반복문을 빠져나간다고 생각하면 안 된다.

## `continue`는 현재 회차의 남은 부분을 건너뛴다

`continue`는 반복문 전체를 끝내지 않는다. 현재 회차의 남은 문장을 건너뛰고 다음 반복으로 진행한다.

```cpp
for (int i = 1; i <= 10; ++i)
{
    if (i % 2 == 0)
    {
        continue;
    }

    std::cout << i << '\n';
}
```

짝수에서는 출력문을 건너뛰므로 1, 3, 5, 7, 9가 출력된다.

`continue`는 반복 종류에 따라 이동하는 위치가 다르다.

```text
for의 continue
현재 본문 → 증감식 → 조건식

while의 continue
현재 본문 → 조건식

do-while의 continue
현재 본문 → 아래쪽 조건식
```

이 차이는 반복 상태를 어디에서 변경하는지에 영향을 준다.

## `for`의 `continue`는 증감식을 실행한다

다음 반복문에서 짝수를 만나면 `continue`를 실행하지만 `++i`는 건너뛰지 않는다.

```cpp
for (int i = 0; i < 5; ++i)
{
    if (i % 2 == 0)
    {
        continue;
    }

    std::cout << i << '\n';
}
```

`continue`는 `for`문의 증감식으로 이동한다. 따라서 `i`는 계속 증가하고 반복은 끝난다.

```text
본문의 continue
       │
       ▼
증감식 ++i
       │
       ▼
조건식 i < 5
```

## `while`의 `continue`는 상태 변경을 건너뛸 수 있다

`while`에는 별도의 증감식 위치가 없다. 상태 변경을 본문 아래에 두고 그 전에 `continue`하면 변경이 실행되지 않는다.

```cpp
int count = 0;

while (count < 5)
{
    if (count == 2)
    {
        continue;
    }

    ++count;
}
```

`count`가 2가 되면 `continue`가 조건식으로 바로 이동한다. `++count`에 도달하지 못하므로 `count`는 계속 2이고 반복이 끝나지 않는다.

상태 변경을 `continue`보다 먼저 수행하면 진행할 수 있다.

```cpp
int count = 0;

while (count < 5)
{
    ++count;

    if (count == 2)
    {
        continue;
    }

    std::cout << count << '\n';
}
```

하지만 변경 위치가 본문의 의미와 맞는지도 확인해야 한다. 카운터 기반 반복에서 이런 문제가 반복된다면 `for`문으로 제어 요소를 한곳에 모으는 것이 더 자연스러울 수 있다.

## `continue`는 예외 조건을 먼저 걸러낼 수 있다

처리할 조건을 깊게 중첩하는 대신 처리하지 않을 경우를 먼저 건너뛸 수 있다.

```cpp
for (int playerIndex = 0; playerIndex < playerCount; ++playerIndex)
{
    if (!IsConnected(playerIndex))
    {
        continue;
    }

    if (IsSpectator(playerIndex))
    {
        continue;
    }

    UpdatePlayer(playerIndex);
}
```

연결되지 않은 플레이어와 관전자 상태를 먼저 제외하므로 핵심 처리인 `UpdatePlayer`가 중첩 안쪽으로 들어가지 않는다.

모든 짧은 조건에 `continue`를 사용해야 하는 것은 아니다. 반복 본문 여러 위치에 `continue`가 흩어지면 어떤 작업이 생략되는지 추적하기 어려울 수 있다. 제외 조건을 앞부분에 모으고 생략되는 작업을 명확히 유지한다.

## 의도적인 무한 반복에는 종료 경로가 따로 있다

조건이 항상 참인 반복문도 문법적으로 유효하다.

```cpp
while (true)
{
    Update();
}
```

게임 루프, 서버 요청 처리, 이벤트 루프처럼 프로그램이 종료될 때까지 계속 실행하는 구조에서는 무한 반복이 의도일 수 있다.

본문 안의 상태에 따라 끝내는 구조도 가능하다.

```cpp
while (true)
{
    int input = 0;
    std::cin >> input;

    if (input == 0)
    {
        break;
    }

    std::cout << "Input: " << input << '\n';
}
```

이 반복은 입력값 0을 만나면 끝난다. 이런 특별한 종료 값을 센티널 값(Sentinel value)이라고 부른다.

무한 반복을 발견했다고 무조건 오류라고 판단하지 않는다. 대신 다음 사항을 확인한다.

- 종료가 필요한 작업인가?
- 종료 경로가 실제로 도달 가능한가?
- 외부 종료 신호를 처리하는가?
- 한 회차가 너무 오래 걸리거나 멈출 가능성이 있는가?
- 반복 중 실패 상태가 계속 유지될 수 있는가?

## 입력 실패를 검사하지 않으면 반복이 멈추지 않을 수 있다

`std::cin`으로 정수를 읽으려는데 문자가 들어오면 스트림이 실패 상태가 된다.

```cpp
int value = 0;

while (true)
{
    std::cin >> value;
    std::cout << value << '\n';
}
```

입력 실패 후에는 추가 입력도 계속 실패할 수 있으므로 반복이 의도와 다르게 빠르게 돌 수 있다. 스트림 추출 결과를 조건으로 사용할 수 있다.

```cpp
int value = 0;

while (std::cin >> value)
{
    std::cout << value << '\n';
}
```

입력에 성공한 동안만 본문을 실행한다. 파일 끝이나 잘못된 입력으로 추출이 실패하면 조건이 `false`가 되어 반복을 종료한다.

실패 후 다시 입력을 받을지, 반복을 끝낼지, 오류 메시지를 출력할지는 프로그램의 입력 정책에 따라 결정한다.

## 반복 조건에서 같은 작업을 두 번 하지 않는다

조건과 본문에서 같은 결과를 반복 계산하면 코드가 불필요하게 복잡해질 수 있다.

```cpp
while (CalculateDistance() > 10.0)
{
    std::cout << CalculateDistance() << '\n';
    MoveCloser();
}
```

`CalculateDistance`가 비용이 큰 함수거나 호출할 때 상태가 달라질 수 있다면 조건에서 검사한 값과 출력한 값이 다를 수도 있다.

한 회차에서 사용할 값을 저장해 흐름을 명확히 할 수 있다.

```cpp
while (true)
{
    double distance = CalculateDistance();

    if (distance <= 10.0)
    {
        break;
    }

    std::cout << distance << '\n';
    MoveCloser();
}
```

거리 계산, 종료 판단, 이동이 한 회차의 순서로 드러난다.

## 반복 횟수가 매우 크면 제어 변수의 범위도 확인한다

반복 제어 변수 역시 자료형의 표현 범위를 가진다.

```cpp
for (int i = 0; i < count; ++i)
{
    Process(i);
}
```

`count`가 `int`의 최댓값보다 클 수 있거나 `++i`가 표현 범위를 벗어날 수 있다면 부호 있는 정수 오버플로가 발생할 수 있다. 컨테이너 크기나 외부 데이터 범위에 맞는 타입을 선택하고 Signed·Unsigned 비교도 함께 확인해야 한다.

반복문 문법이 데이터 범위를 자동으로 보장해 주지는 않는다.

## 전체 실습 코드

최대 라운드 동안 몬스터를 공격하고, 특정 라운드는 공격을 건너뛰는 전투 예제다.

```cpp
#include <algorithm>
#include <iostream>

int main()
{
    constexpr int MaxRounds = 7;
    constexpr int Damage = 18;

    int monsterHp = 80;
    bool defeated = false;

    for (int round = 1; round <= MaxRounds; ++round)
    {
        std::cout << "Round " << round << '\n';

        bool attackMissed = round % 3 == 0;

        if (attackMissed)
        {
            std::cout << "공격이 빗나갔습니다.\n";
            continue;
        }

        monsterHp = std::max(0, monsterHp - Damage);
        std::cout << "Monster HP: " << monsterHp << '\n';

        if (monsterHp == 0)
        {
            defeated = true;
            std::cout << "몬스터를 처치했습니다.\n";
            break;
        }
    }

    if (!defeated)
    {
        std::cout << "제한 라운드 안에 처치하지 못했습니다.\n";
    }

    std::cout << "Odd numbers: ";

    for (int number = 1; number <= 10; ++number)
    {
        if (number % 2 == 0)
        {
            continue;
        }

        std::cout << number << ' ';
    }

    std::cout << '\n';
}
```

전투 반복의 흐름은 다음과 같다.

```text
round 초기화
      │
      ▼
최대 라운드 검사
      │
      ├── 공격 실패 → continue → ++round
      │
      ├── 공격 성공 → HP 감소
      │                  │
      │                  ├── HP == 0 → break
      │                  └── 생존 → ++round
      │
      └── 조건 false → 반복 종료
```

이 예제에서는 다음 내용을 확인할 수 있다.

- `for`문의 증감식은 `continue` 이후에도 실행된다.
- 세 번째 라운드마다 공격 처리를 건너뛴다.
- HP가 0이 되면 `break`로 반복을 즉시 끝낸다.
- 반복 종료 후 `defeated`로 종료 이유를 구분한다.
- 두 번째 반복은 `continue`를 이용해 짝수를 제외한다.
