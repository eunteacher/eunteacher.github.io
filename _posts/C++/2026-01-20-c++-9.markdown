# [C++] const는 저장 위치가 아니라 변경 가능성을 나타낸다

변하지 않는 값인 **상수(Constant)**의 개념과, 프로그램 실행 시 데이터가 저장되는 **메모리 구조(Memory Layout)**에 대한 정리

---

## `const`가 보장하는 것

### 1) 상수 (const)
* **개념:** 이름을 통해 해당 객체를 변경하지 못하게 제한한다.
* **특징:**
  * 해당 `const` 객체의 수명 동안 직접 값을 바꿀 수 없다.
  * 기본형 `const` 객체는 사용할 값을 가지고 있어야 하므로 보통 선언과 동시에 초기화한다.
  * 매직 넘버(Magic Number)를 제거하고 코드의 의도를 명확히 하는 데 유용함

### `const`와 저장 기간을 분리해서 보기
프로그램 실행 시 메모리는 크게 4가지 영역으로 구분됨 `[코드][데이터][힙][스택]`

* **정적 저장 기간:** 전역 변수와 정적 변수는 프로그램 실행 기간 동안 존재한다.
  * **.data:** 초기값이 **있는** 변수가 저장됨
  * **.bss:** 초기값이 **없는** 변수가 저장됨 (0으로 자동 초기화)
  * **.rodata (Read-Only Data):** 문자열 상수나 `const` 전역 변수 등 읽기 전용 데이터가 저장됨
* **자동 저장 기간:** 일반적인 지역 변수는 블록에 진입할 때 생기고 블록을 벗어날 때 소멸한다. 구현은 보통 스택을 사용하지만 C++ 언어가 물리적 저장 위치를 직접 보장하는 것은 아니다.

`const` 여부와 저장 기간은 서로 다른 축이다. 전역 `const`, 지역 `const`, 정적 지역 `const`는 모두 가능하며 실제 섹션 배치는 컴파일러와 링커가 결정한다.

## 이름 있는 상수로 의도 드러내기

`const`를 활용한 비트 플래그 설정과 전역/지역 변수의 메모리 저장 위치를 확인하는 예제

```cpp
#include <iostream>
using namespace std;

// [전역 변수]
// - 데이터 영역에 저장되며 프로그램 전체에서 접근 가능

// 1. 상수 (const)
// - 초기값을 반드시 지정해야 함
// - 비트 플래그 등의 상태값 정의에 유용
const int AIR = 0;
const int STUN = 1;
const int POLYMORPH = 2;
const int FEAR = 3;
const int INVINCIBLE = 4;

// unsigned 사용 이유: 우측 시프트(>>) 시 부호 비트 채움 방지
unsigned char flag;

// 2. 데이터 영역 상세
// .data 영역 (초기값 있음)
int a = 2;

// .bss 영역 (초기값 없음)
int b;

// .rodata 영역 (읽기 전용)
const char* msg = "Hello World";

int main()
{
#pragma region const 활용 (BitFlag)
    // 0b0000 [무적][공포][변이][스턴][공중부양]

    // 무적 상태 켜기 (Set)
    flag = (1 << INVINCIBLE);
    // flag = 1 << 4 (16, 0b10000)

    // 변이 상태 추가 (Add)
    flag |= (1 << POLYMORPH);
    // flag = 16 | 4 (20, 0b10100)

    // 무적 상태 확인 (Check)
    bool bInvincible = (flag & (1 << INVINCIBLE)) != 0;

    // 복합 상태 확인 (무적 or 스턴)
unsigned char BitMask = (1 << INVINCIBLE) | (1 << STUN);
    bool bStunOrInvincible = (flag & BitMask) != 0;
#pragma endregion

#pragma region 스택 영역
    // [스택 영역]
    // - 함수 내부의 지역 변수
    // - 함수 종료 시 메모리 해제됨

    int c = 3;

    // 함수 내부의 const는 스택 영역에 저장됨
    const int TEST = 0;
#pragma endregion

    return 0;
}
```

## 객체의 수명과 접근 범위

* **데이터의 수명 (Life Cycle)**
  * **전역 변수:** 프로그램 시작부터 종료까지 유지됨 (데이터 영역)
  * **지역 변수:** 함수가 실행되는 동안에만 유효함 (스택 영역)
* **const의 활용**
  * 코드 내 하드코딩된 숫자(매직 넘버)를 피하고 `INVINCIBLE`처럼 의미 있는 이름을 부여하여 가독성을 높일 수 있음
  * 비트 연산 시 각 비트의 위치를 `const`로 정의해두면 실수를 줄일 수 있음

---

## 잘못 외우기 쉬운 부분

* **저장 위치:** 전역 `const`는 흔히 읽기 전용 영역에 놓이지만, 최적화로 저장 공간 자체가 없어질 수도 있다. 지역 `const` 역시 반드시 스택 메모리를 차지한다고 단정할 수 없다.
* **초기화 필수:** `const int a;` 처럼 선언만 하고 값을 넣지 않으면 컴파일 에러가 발생함. 반드시 `const int a = 10;` 처럼 선언과 동시에 값을 줘야 함
---

## 마무리

`const`는 “어디에 저장되는가”보다 “이 경로로 값을 바꿀 수 있는가”에 관한 언어 규칙이다. 저장 기간, 스코프, 링커가 만드는 메모리 배치는 따로 구분해서 이해해야 한다. 다음 글에서는 이름이 보이는 범위와 타입 변환을 다룬다.
