# [C++] 상수(const)의 특징과 메모리 영역별 데이터 저장 방식

변하지 않는 값인 **상수(Constant)**의 개념과, 프로그램 실행 시 데이터가 저장되는 **메모리 구조(Memory Layout)**에 대한 정리

---

## 이론 정리

### 1) 상수 (const)
* **개념:** `constant`의 약자로, 변수를 **상수화**하여 값을 변경할 수 없게 만듦
* **특징:**
  * 한번 정해지면 절대 바뀌지 않는 값을 표현할 때 사용함
  * 선언과 동시에 **반드시 초기값**을 지정해야 함
  * 매직 넘버(Magic Number)를 제거하고 코드의 의도를 명확히 하는 데 유용함

### 2) 메모리 구조 (Memory Layout)
프로그램 실행 시 메모리는 크게 4가지 영역으로 구분됨 `[코드][데이터][힙][스택]`

* **데이터 영역 (Data Segment):** 전역 변수(Global Variable)나 정적 변수(Static)가 저장됨. 프로그램 시작 시 할당되고 종료 시 소멸함
  * **.data:** 초기값이 **있는** 변수가 저장됨
  * **.bss:** 초기값이 **없는** 변수가 저장됨 (0으로 자동 초기화)
  * **.rodata (Read-Only Data):** 문자열 상수나 `const` 전역 변수 등 읽기 전용 데이터가 저장됨
* **스택 영역 (Stack Segment):**
  * 함수 내부의 **지역 변수(Local Variable)**와 매개 변수가 저장됨
  * 함수 호출 시 할당되고, 함수 종료 시 데이터가 날아감(Pop)
  * 임시적인 데이터를 저장하는 용도로 사용됨

---

## 소스코드

`const`를 활용한 비트 플래그 설정과 전역/지역 변수의 메모리 저장 위치를 확인하는 예제

```cpp
#include <iostream>
using namespace std;

// [전역 변수]
// - 데이터 영역에 저장되며 프로그램 전체에서 접근 가능

// 1. 상수 (const)
// - 초기값을 반드시 지정해야 함
// - 비트 플래그 등의 상태값 정의에 유용
const int AIR = 0;
const int STUN = 1;
const int POLYMORPH = 2;
const int FEAR = 3;
const int INVINCIBLE = 4;

// unsigned 사용 이유: 우측 시프트(>>) 시 부호 비트 채움 방지
unsigned char flag;

// 2. 데이터 영역 상세
// .data 영역 (초기값 있음)
int a = 2;

// .bss 영역 (초기값 없음)
int b;

// .rodata 영역 (읽기 전용)
const char* msg = "Hello World";

int main()
{
#pragma region const 활용 (BitFlag)
    // 0b0000 [무적][공포][변이][스턴][공중부양]

    // 무적 상태 켜기 (Set)
    flag = (1 << INVINCIBLE);
    // flag = 1 << 4 (16, 0b10000)

    // 변이 상태 추가 (Add)
    flag |= (1 << POLYMORPH);
    // flag = 16 | 4 (20, 0b10100)

    // 무적 상태 확인 (Check)
    bool bInvincible = (flag & (1 << INVINCIBLE)) != 0;

    // 복합 상태 확인 (무적 or 스턴)
    bool BitMask = (1 << INVINCIBLE) | (1 << STUN);
    bool bStunOrInvincible = (flag & BitMask) != 0;
#pragma endregion

#pragma region 스택 영역
    // [스택 영역]
    // - 함수 내부의 지역 변수
    // - 함수 종료 시 메모리 해제됨

    int c = 3;

    // 함수 내부의 const는 스택 영역에 저장됨
    const int TEST = 0;
#pragma endregion

    return 0;
}
```

## 종합의견

* **데이터의 수명 (Life Cycle)**
  * **전역 변수:** 프로그램 시작부터 종료까지 유지됨 (데이터 영역)
  * **지역 변수:** 함수가 실행되는 동안에만 유효함 (스택 영역)
* **const의 활용**
  * 코드 내 하드코딩된 숫자(매직 넘버)를 피하고 `INVINCIBLE`처럼 의미 있는 이름을 부여하여 가독성을 높일 수 있음
  * 비트 연산 시 각 비트의 위치를 `const`로 정의해두면 실수를 줄일 수 있음

---

## Tip

* **const의 저장 위치:** `const` 변수라도 전역으로 선언하면 **.rodata(읽기 전용 데이터)** 영역에, 함수 내부에서 선언하면 **스택** 영역에 저장됨. 즉, 선언 위치에 따라 메모리 관리 방식이 다름
* **초기화 필수:** `const int a;` 처럼 선언만 하고 값을 넣지 않으면 컴파일 에러가 발생함. 반드시 `const int a = 10;` 처럼 선언과 동시에 값을 줘야 함
