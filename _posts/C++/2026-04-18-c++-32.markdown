C++ 27편에서는 문자 배열과 문자열 리터럴, `std::string`, `std::string_view`의 소유권과 수명 차이를 살펴봤다. 이번에는 null 문자로 끝나는 C 스타일 문자열의 길이, 복사, 결합, 비교와 뒤집기를 직접 구현한다.

반복문 자체는 어렵지 않지만 포인터 하나만 받아서는 배열 용량을 알 수 없다는 문제가 있다. 문자열의 끝을 찾는 과정과 쓸 수 있는 버퍼 범위를 함께 다루지 않으면 배열 경계를 넘어설 수 있다.

따라서 이번 실습의 핵심은 표준 함수를 흉내 내는 데 그치지 않는다. 각 함수가 호출 전에 요구하는 조건과 성공한 뒤 보장하는 결과를 코드에 표현한다.

## 문자 배열 크기와 문자열 길이는 다르다

크기 100인 문자 배열에 `"Hello"`를 저장한다.

```cpp
char text[100] = "Hello";
```

배열의 앞부분에는 다음 값이 들어 있다.

```text
인덱스    0    1    2    3    4    5    6 ... 99
값       'H'  'e'  'l'  'l'  'o' '\0'  0 ...  0
```

이 배열에는 서로 다른 두 크기가 존재한다.

```cpp
std::size_t bufferSize = sizeof(text);
std::size_t stringLength = std::char_traits<char>::length(text);
```

```text
bufferSize    = 100  배열이 가진 char 요소 수
stringLength  = 5    null 문자 앞에 있는 문자 수
```

`sizeof(text)`는 현재 범위에서 배열 타입이 유지될 때 전체 바이트 크기를 계산한다. `char`의 크기는 정의상 1바이트이므로 이 배열에서는 요소 수와 바이트 수가 모두 100이다.

문자열 길이에는 마지막 `\0`을 포함하지 않는다. 반면 문자열을 다른 배열에 복사하려면 실제 문자 다섯 개와 null 문자 한 개를 위한 공간이 필요하다.

```text
"Hello"를 저장하는 데 필요한 최소 용량 = 5 + 1
```

## null 문자는 문자열 탐색의 종료 조건이다

C 스타일 문자열의 길이를 직접 구하면 다음과 같다.

```cpp
std::size_t StringLength(const char* text)
{
    std::size_t length = 0;

    while (text[length] != '\0')
    {
        ++length;
    }

    return length;
}
```

이 함수가 올바르게 끝나려면 호출자가 두 조건을 보장해야 한다.

- `text`가 `nullptr`이 아니다.
- 접근 가능한 범위 안에 null 문자가 존재한다.

포인터만으로는 두 번째 조건을 확인할 수 없다.

```cpp
char characters[5] = {'H', 'e', 'l', 'l', 'o'};
// StringLength(characters); // 범위 안에 null 문자가 없음
```

반복문은 다섯 요소 뒤에서도 null 문자를 찾으려고 계속 읽는다. 배열 경계를 벗어난 접근은 정의되지 않은 동작이다.

표준 `std::strlen`도 포인터가 가리키는 범위 안에 null 문자가 있다는 전제에서 동작한다. 표준 함수라는 사실이 잘못된 입력 버퍼를 자동으로 안전하게 만들지는 않는다.

## 포인터와 용량을 함께 받으면 탐색 범위를 제한할 수 있다

`std::span`으로 문자 버퍼와 요소 수를 함께 전달한다.

```cpp
#include <optional>
#include <span>

std::optional<std::size_t> FindStringLength(std::span<const char> buffer)
{
    for (std::size_t index = 0; index < buffer.size(); ++index)
    {
        if (buffer[index] == '\0')
        {
            return index;
        }
    }

    return std::nullopt;
}
```

반환값은 두 상태를 구분한다.

- 숫자가 있음: 해당 인덱스에서 null 문자를 발견했다.
- `std::nullopt`: 전달받은 범위 안에 null 문자가 없다.

```cpp
char valid[6] = "Hello";
char invalid[5] = {'H', 'e', 'l', 'l', 'o'};

auto validLength = FindStringLength(valid);
auto invalidLength = FindStringLength(invalid);
```

`validLength`는 5를 담고 `invalidLength`는 값이 없다. 실제 배열 범위 밖을 읽지 않고 실패를 표현할 수 있다.

## 문자열 복사는 null 문자까지 포함해야 한다

원본 코드의 복사 반복은 문자열 길이와 같은 인덱스까지 복사한다.

```cpp
while (index <= length)
{
    destination[index] = source[index];
    ++index;
}
```

`index == length`일 때 복사하는 값이 null 문자다. 이 마지막 대입이 빠지면 목적지 배열은 문자 데이터만 가진 채 C 스타일 문자열의 종료 조건을 잃을 수 있다.

하지만 목적지 포인터만으로는 복사할 공간이 충분한지 알 수 없다.

```cpp
char destination[4];
// "Hello\0"는 6칸이 필요하다.
```

문자열을 쓰는 함수에는 목적지 용량이 필요하다.

## 복사 전에 필요한 공간을 먼저 확인한다

원본 문자열은 읽기만 하므로 `std::string_view`로 받고, 목적지는 수정 가능한 `std::span<char>`로 받는다.

```cpp
#include <span>
#include <string_view>

bool CopyString(std::span<char> destination, std::string_view source)
{
    if (source.size() >= destination.size())
    {
        return false;
    }

    for (std::size_t index = 0; index < source.size(); ++index)
    {
        destination[index] = source[index];
    }

    destination[source.size()] = '\0';
    return true;
}
```

조건이 `source.size() > destination.size()`가 아니라 `>=`인 이유는 null 문자 한 칸이 추가로 필요하기 때문이다.

```text
source.size() = 5
destination.size() = 6  성공
destination.size() = 5  실패: null 문자를 쓸 공간이 없음
```

공간 검사를 모든 대입보다 먼저 실행하므로 실패하면 목적지 내용을 일부만 바꾸지 않는다.

`std::string_view`는 null 종료 여부가 아니라 문자 범위와 길이를 표현한다. 복사 함수가 마지막에 null 문자를 직접 추가해 목적지를 C 스타일 문자열로 만든다.

## 원본 매개변수에는 수정 권한이 필요하지 않다

기존 복사 함수는 원본 문자열도 `char*`로 받는다.

```cpp
char* StrCopy(char* destination, char* source);
```

하지만 함수는 `source`의 문자를 읽기만 한다. 수정 권한이 필요하지 않은 입력에 `char*`를 요구하면 문자열 리터럴이나 읽기 전용 버퍼를 직접 전달할 수 없다.

원시 포인터 인터페이스를 유지한다면 최소한 다음처럼 표현해야 한다.

```cpp
char* StrCopy(char* destination, const char* source);
```

이번 개선 예제는 여기서 더 나아가 다음 정보를 타입에 포함한다.

```text
std::span<char>       수정 가능한 목적지와 용량
std::string_view      읽기 전용 원본과 문자 수
```

매개변수 타입은 구현에 필요한 권한과 범위를 함께 표현해야 한다.

## 문자열 결합은 현재 길이 뒤에서 시작한다

`"Hello"` 뒤에 `" World"`를 붙이려면 기존 null 문자 위치부터 새 문자를 덮어쓴다.

```text
결합 전

H e l l o \0 _ _ _ _ _ _ _ _
          ↑ 현재 길이 5

결합 후

H e l l o   W o r l d \0 _ _ _
```

필요한 최종 용량은 다음과 같다.

```text
현재 길이 + 추가 문자열 길이 + null 문자 1개
```

결합 함수는 먼저 목적지 안에서 현재 문자열 길이를 찾는다.

```cpp
bool AppendString(std::span<char> destination, std::string_view suffix)
{
    std::optional<std::size_t> currentLength = FindStringLength(destination);

    if (!currentLength.has_value())
    {
        return false;
    }

    std::size_t remainingCapacity = destination.size() - *currentLength;
    if (suffix.size() >= remainingCapacity)
    {
        return false;
    }

    for (std::size_t index = 0; index < suffix.size(); ++index)
    {
        destination[*currentLength + index] = suffix[index];
    }

    destination[*currentLength + suffix.size()] = '\0';
    return true;
}
```

함수는 두 가지 실패를 구분하지 않고 `false`로 반환한다.

- 기존 목적지 범위 안에 null 문자가 없다.
- 추가 문자열과 새 null 문자를 저장할 공간이 부족하다.

실패 이유까지 필요하다면 열거형이나 별도 결과 타입으로 확장할 수 있다. 이번 예제는 성공 여부와 버퍼 불변성에 집중한다.

## 문자 배열의 `==`는 문자열 내용을 비교하지 않는다

서로 다른 배열에 같은 내용을 저장한다.

```cpp
char first[16] = "Hello";
char second[16] = "Hello";
```

대부분의 표현식에서 배열 이름은 첫 요소를 가리키는 포인터로 변환된다. 따라서 다음 비교는 문자열 문자가 아니라 두 배열의 시작 주소를 비교한다.

```cpp
bool sameAddress = first == second;
```

`first`와 `second`는 별도 배열이므로 같은 내용을 가져도 시작 주소는 다르다.

문자열 내용 비교는 같은 인덱스의 문자를 순서대로 확인해야 한다.

```text
H == H
e == e
l == l
l == l
o == o
두 문자열이 함께 끝남
```

주소 동일성과 내용 동일성은 서로 다른 조건이다.

## 문자열 비교는 처음 다른 문자의 순서를 반환한다

두 문자열을 사전식으로 비교한다.

```cpp
int CompareStrings(std::string_view left, std::string_view right)
{
    std::size_t commonLength = std::min(left.size(), right.size());

    for (std::size_t index = 0; index < commonLength; ++index)
    {
        unsigned char leftCharacter = static_cast<unsigned char>(left[index]);
        unsigned char rightCharacter = static_cast<unsigned char>(right[index]);

        if (leftCharacter < rightCharacter)
        {
            return -1;
        }

        if (leftCharacter > rightCharacter)
        {
            return 1;
        }
    }

    if (left.size() < right.size())
    {
        return -1;
    }

    if (left.size() > right.size())
    {
        return 1;
    }

    return 0;
}
```

공통 구간에서 다른 문자를 만나면 해당 바이트 값을 비교한다. 공통 구간이 모두 같다면 더 짧은 문자열이 앞선다.

```text
"Hella" < "Hello"   'a'가 'o'보다 앞섬
"Hell"  < "Hello"   공통 문자는 같고 왼쪽이 먼저 끝남
"Hello" == "Hello"  길이와 모든 문자가 같음
```

`std::strcmp`가 보장하는 것도 음수, 0, 양수라는 부호다. 구현이 반드시 정확히 `-1`, `0`, `1`을 반환한다고 가정하지 않는다. 이번 직접 구현은 사용하기 편하도록 세 값으로 정규화한다.

`char`의 부호 여부는 구현에 따라 달라질 수 있으므로 바이트 순서를 비교할 때 `unsigned char`로 변환한다. 이 비교는 바이트 기반 사전식 순서이며 한국어의 언어학적 정렬 순서를 처리하는 기능은 아니다.

## 문자열 뒤집기는 null 문자를 움직이지 않는다

길이 5인 `"Hello"`를 뒤집을 때 첫 문자와 마지막 문자, 두 번째 문자와 끝에서 두 번째 문자를 교환한다.

```text
H e l l o \0
↕       ↕
o e l l H \0
  ↕   ↕
o l l e H \0
```

교환 횟수는 문자열 길이의 절반이다.

```cpp
bool ReverseString(std::span<char> buffer)
{
    std::optional<std::size_t> length = FindStringLength(buffer);

    if (!length.has_value())
    {
        return false;
    }

    for (std::size_t index = 0; index < *length / 2; ++index)
    {
        std::swap(buffer[index], buffer[*length - 1 - index]);
    }

    return true;
}
```

null 문자 인덱스는 `*length`다. 마지막 실제 문자 인덱스는 `*length - 1`이므로 교환 대상 계산에 1을 뺀다.

빈 문자열은 길이가 0이어서 반복문을 실행하지 않고 성공한다. null 문자가 없는 버퍼는 문자열로 뒤집지 않고 실패한다.

## 포인터 산술은 요소 크기를 자동으로 반영한다

원본 코드에는 배열 접근을 포인터 형태로 바꾸려는 주석이 있다.

```cpp
destination[index] = source[index];
```

같은 접근을 역참조 형태로 쓰면 다음과 같다.

```cpp
*(destination + index) = *(source + index);
```

`char*`는 한 요소의 크기가 1이므로 바이트 계산과 우연히 비슷하게 보인다. 하지만 포인터 산술은 대상 타입의 크기를 이미 반영하므로 `sizeof(char) * index`를 직접 넣을 필요가 없다.

```cpp
// 불필요한 표현
*(destination + sizeof(char) * index) = *(source + sizeof(char) * index);
```

`sizeof(char)`는 항상 1이어서 결과는 같지만 다른 타입 포인터에 같은 습관을 적용하면 잘못된 위치로 이동할 수 있다. 인덱스는 바이트 수가 아니라 요소 수로 생각한다.

## 실패할 수 있는 쓰기 함수는 기존 내용을 보존한다

복사와 결합 함수는 용량을 먼저 검사한 뒤 쓰기를 시작한다.

```cpp
std::array<char, 6> text{};
bool copied = CopyString(text, "Hello");
bool appended = AppendString(text, "!");
```

첫 번째 복사는 정확히 여섯 칸을 사용해 성공한다. 그 뒤 느낌표를 붙이려면 일곱 칸이 필요하므로 결합은 실패한다.

```text
CopyString 이후:   H e l l o \0
AppendString 실패: H e l l o \0  기존 내용 유지
```

공간이 부족한 상태에서 가능한 만큼만 복사하면 호출자는 잘린 문자열이 유효한 결과인지 실패 중간 상태인지 구분하기 어렵다. 이번 계약은 전체 작업이 가능할 때만 버퍼를 변경한다.

일부 프로그램은 잘린 결과를 허용할 수 있다. 그 경우에는 실제 기록한 문자 수와 잘림 여부를 함께 반환하도록 다른 계약을 설계해야 한다.

## 고정된 버퍼로 각 조건을 검증한다

문자열 함수는 난수나 사용자 입력 없이 경계 조건을 직접 확인할 수 있다.

```cpp
#include <array>
#include <cassert>

void VerifyStringFunctions()
{
    std::array<char, 16> text{};
    assert(CopyString(text, "Hello"));
    assert(std::string_view(text.data()) == "Hello");

    assert(AppendString(text, " World"));
    assert(std::string_view(text.data()) == "Hello World");

    assert(ReverseString(text));
    assert(std::string_view(text.data()) == "dlroW olleH");

    assert(CompareStrings("Hella", "Hello") < 0);
    assert(CompareStrings("Hello", "Hello") == 0);
    assert(CompareStrings("Hello!", "Hello") > 0);

    std::array<char, 6> exact{};
    assert(CopyString(exact, "Hello"));
    assert(!AppendString(exact, "!"));
    assert(std::string_view(exact.data()) == "Hello");

    std::array<char, 5> unterminated{'H', 'e', 'l', 'l', 'o'};
    assert(!FindStringLength(unterminated).has_value());
    assert(!ReverseString(unterminated));
}
```

정상 문자열만 확인하지 않고 정확히 맞는 용량, 공간 부족과 null 문자 누락도 검사한다. 경계에서 실패하는 함수일수록 성공 사례와 실패 사례를 함께 확인해야 한다.

## 전체 수동 구현

앞에서 만든 범위 기반 문자열 함수를 하나의 파일로 구성한다.

```cpp
#include <algorithm>
#include <array>
#include <cassert>
#include <cstddef>
#include <iostream>
#include <optional>
#include <span>
#include <string_view>
#include <utility>

std::optional<std::size_t> FindStringLength(std::span<const char> buffer)
{
    for (std::size_t index = 0; index < buffer.size(); ++index)
    {
        if (buffer[index] == '\0')
        {
            return index;
        }
    }

    return std::nullopt;
}

bool CopyString(std::span<char> destination, std::string_view source)
{
    if (source.size() >= destination.size())
    {
        return false;
    }

    for (std::size_t index = 0; index < source.size(); ++index)
    {
        destination[index] = source[index];
    }

    destination[source.size()] = '\0';
    return true;
}

bool AppendString(std::span<char> destination, std::string_view suffix)
{
    std::optional<std::size_t> currentLength = FindStringLength(destination);

    if (!currentLength.has_value())
    {
        return false;
    }

    std::size_t remainingCapacity = destination.size() - *currentLength;
    if (suffix.size() >= remainingCapacity)
    {
        return false;
    }

    for (std::size_t index = 0; index < suffix.size(); ++index)
    {
        destination[*currentLength + index] = suffix[index];
    }

    destination[*currentLength + suffix.size()] = '\0';
    return true;
}

int CompareStrings(std::string_view left, std::string_view right)
{
    std::size_t commonLength = std::min(left.size(), right.size());

    for (std::size_t index = 0; index < commonLength; ++index)
    {
        unsigned char leftCharacter = static_cast<unsigned char>(left[index]);
        unsigned char rightCharacter = static_cast<unsigned char>(right[index]);

        if (leftCharacter < rightCharacter)
        {
            return -1;
        }

        if (leftCharacter > rightCharacter)
        {
            return 1;
        }
    }

    if (left.size() < right.size())
    {
        return -1;
    }

    if (left.size() > right.size())
    {
        return 1;
    }

    return 0;
}

bool ReverseString(std::span<char> buffer)
{
    std::optional<std::size_t> length = FindStringLength(buffer);

    if (!length.has_value())
    {
        return false;
    }

    for (std::size_t index = 0; index < *length / 2; ++index)
    {
        std::swap(buffer[index], buffer[*length - 1 - index]);
    }

    return true;
}

void VerifyStringFunctions()
{
    std::array<char, 16> text{};
    assert(CopyString(text, "Hello"));
    assert(std::string_view(text.data()) == "Hello");

    assert(AppendString(text, " World"));
    assert(std::string_view(text.data()) == "Hello World");

    assert(ReverseString(text));
    assert(std::string_view(text.data()) == "dlroW olleH");

    assert(CompareStrings("Hella", "Hello") < 0);
    assert(CompareStrings("Hello", "Hello") == 0);
    assert(CompareStrings("Hello!", "Hello") > 0);

    std::array<char, 6> exact{};
    assert(CopyString(exact, "Hello"));
    assert(!AppendString(exact, "!"));
    assert(std::string_view(exact.data()) == "Hello");

    std::array<char, 5> unterminated{'H', 'e', 'l', 'l', 'o'};
    assert(!FindStringLength(unterminated).has_value());
    assert(!ReverseString(unterminated));
}

int main()
{
    VerifyStringFunctions();

    std::array<char, 32> message{};
    if (!CopyString(message, "Hello") || !AppendString(message, " C++"))
    {
        std::cout << "The destination buffer is too small.\n";
        return 1;
    }

    std::cout << message.data() << '\n';
}
```

이 구현은 C++20의 `std::span`을 사용한다. 목적지의 용량을 함수에 전달하고, 쓰기 전에 전체 결과가 들어가는지 확인한다.

`std::string_view`로 받은 입력은 null 문자에 의존하지 않는다. 따라서 일부 문자 범위만 복사하거나 비교할 수도 있다. 목적지에 기록할 때만 마지막 null 문자를 명시적으로 추가한다.

## 실제 프로그램에서는 소유 문자열을 우선 검토한다

직접 만든 함수는 문자 배열의 경계와 null 종료 규칙을 학습하기 위한 예제다. 일반 애플리케이션에서 문자열을 소유하고 결합해야 한다면 `std::string`이 더 자연스러운 경우가 많다.

```cpp
#include <algorithm>
#include <string>

std::string message = "Hello";
message += " World";
std::reverse(message.begin(), message.end());
```

`std::string`은 저장 공간을 소유하고 필요한 크기를 관리한다. 직접 목적지 배열 용량과 null 문자 위치를 계산할 필요가 없다.

그렇다고 C 스타일 문자열 규칙을 몰라도 된다는 뜻은 아니다. 운영체제 API, C 라이브러리, 직렬화 형식과 기존 엔진 인터페이스에서는 `const char*`와 고정 버퍼를 만날 수 있다. 그때 포인터가 가리키는 범위와 null 종료 전제를 구분할 수 있어야 한다.

## 문자열 함수를 검토할 때 확인할 기준

1. 배열의 전체 용량과 현재 문자열 길이를 구분하는가?
2. null 문자를 저장할 한 칸까지 계산하는가?
3. 포인터만 받은 함수가 버퍼 크기를 안다고 가정하지 않는가?
4. 읽기 전용 원본에 불필요한 수정 권한을 요구하지 않는가?
5. 복사와 결합 전에 전체 결과가 들어가는지 검사하는가?
6. 실패하기 전에 목적지 일부를 먼저 변경하지 않는가?
7. 문자 배열의 `==`를 내용 비교로 오해하지 않는가?
8. 비교 결과의 정확한 숫자보다 음수·0·양수의 의미를 사용하는가?
9. 뒤집을 때 null 문자를 교환 대상에 포함하지 않는가?
10. null 문자가 없는 버퍼를 C 스타일 문자열처럼 읽지 않는가?

문자열 함수의 반복문은 짧지만 안전성은 함수 밖의 전제에 크게 의존한다. 포인터와 함께 용량을 전달하고 실패 상태를 표현하면 그 전제를 호출자와 구현이 함께 확인할 수 있다.
