# [C++] 데이터의 연산: 할당과 산술(Arithmetic)

## 1. 소스 코드 (Source Code)

```cpp
#include <iostream>
using namespace std;

// 데이터의 연산 (Data Operation)
// 데이터를 가공하고 메모리에 할당하는 과정

// 1. 데이터 할당 (Allocation)
// 프로그램 실행 시 저장장치(SSD/HDD)의 정보가 RAM(메모리)에 로드됨
// 변수 선언은 메모리에 특정 크기의 공간(바구니)을 잡는 행위임

int a = 1; // a라는 메모리 공간을 할당하고 초기값 1 저장
int b = 2; // b라는 메모리 공간을 할당하고 초기값 2 저장

int main()
{
    std::cout << "Hello World!\n";

#pragma region 산술 연산
    // 1. 대입 연산 (Assignment)

    // a = b : b의 값을 a 메모리 공간에 복사 (Copy)
    a = b;

    // 연산 순서: 우측에서 좌측으로 진행 (Right-to-Left)
    // b = 3 수행 후, 그 결과값을 a에 대입
    a = b = 3;

    // 2. 사칙 연산 (Arithmetic)
    // 활용: 게임 내 데미지 계산, 체력 감소, 루프 카운트 등

    a = b + 3; // 덧셈 (Add)
    a = b - 3; // 뺄셈 (Sub)
    a = b * 3; // 곱셈 (Mul)
    a = b / 3; // 나눗셈 (Div) - 정수 나눗셈은 몫만 반환
    a = b % 3; // 나머지 (Mod) - 나눗셈 후 나머지 반환

    // 3. 복합 대입 연산자 (Compound Assignment)
    // 산술 연산과 대입을 한 번에 수행
    a += 3; // a = a + 3
    a -= 3; // a = a - 3
    a *= 3; // a = a * 3
    a /= 3; // a = a / 3
    a %= 3; // a = a % 3

    // 4. 증감 연산자 (Increment/Decrement)
    // 변수의 값을 1 증가시키거나 감소시킴
    // CPU 레벨에서는 add 대신 inc 명령어를 사용하여 더 효율적일 수 있음

    a = a + 1; // 일반적인 덧셈
    a++;       // 후위 증가
    ++a;       // 전위 증가
    a--;       // 후위 감소
    --a;       // 전위 감소

    // 전위(Prefix) vs 후위(Postfix) 차이
    b = a++; // 대입 후 증가: b = a 수행 후 a += 1
    b = ++a; // 증가 후 대입: a += 1 수행 후 b = a

    // 5. 연산자 우선순위 (Precedence)
    // 곱셈(*), 나눗셈(/)이 덧셈(+), 뺄셈(-)보다 우선순위가 높음
    b = a + 1 * 3;

#pragma endregion
}
```

## 2. 이론 정리 (Study Notes)

### 데이터 할당과 메모리
* **로드(Load)**: 실행 파일(SSD/HDD)이 **RAM(메모리)**에 올라가는 과정
* **할당(Allocation)**: 변수 선언 시, OS가 해당 데이터를 저장할 **유효한 메모리 공간(주소)**을 내어주는 행위

### 산술 연산자 (Arithmetic Operators)

| 연산자 | 기호 | 설명 | 수식 예시 | 비고 |
| :--- | :---: | :--- | :--- | :--- |
| **대입** | `=` | 우항의 값을 좌항에 복사 | $a \leftarrow b$ | 우측 결합성 (Right-to-Left) |
| **덧셈** | `+` | 두 피연산자의 합 | $a + b$ | |
| **뺄셈** | `-` | 두 피연산자의 차 | $a - b$ | |
| **곱셈** | `*` | 두 피연산자의 곱 | $a \times b$ | 우선순위 높음 |
| **나눗셈** | `/` | 몫을 반환 | $a / b$ | **정수형끼리 연산 시 소수점 버림** |
| **나머지** | `%` | 나머지를 반환 | $a \pmod b$ | **정수형 데이터에서만 사용 가능** |

### 증감 연산자 (Increment/Decrement)
변수의 값을 1씩 변경. 위치에 따라 동작 순서가 다름

* **전위 연산 (Prefix, `++a`)**:
  1.  변수의 값을 먼저 1 증가
  2.  증가된 값을 수식에 사용
      $$a \leftarrow a + 1, \quad \text{return } a$$
* **후위 연산 (Postfix, `a++`)**:
  1.  현재 변수의 값을 먼저 반환(사용)
  2.  나중에 변수의 값을 1 증가
      $$\text{temp} \leftarrow a, \quad a \leftarrow a + 1, \quad \text{return temp}$$

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항
* **정수 나눗셈의 함정**: `int`형 끼리의 나눗셈(`5 / 2`) 결과는 `2.5`가 아니라 **`2`**임 (소수점 절삭). 정확한 실수 값이 필요하면 `float`나 `double`로 형변환(Casting) 필수
* **0으로 나누기 (Divide by Zero)**: 분모가 0일 경우 프로그램이 **비정상 종료(Crash)**되므로, 나눗셈 전에는 반드시 0 체크를 수행해야 함
* **연산자 우선순위**: `b = a + 1 * 3` 처럼 섞여 있을 땐 곱셈이 먼저 수행됨. 가독성을 위해 **괄호 `()`**를 적극 활용하는 것이 좋음

### Tip
* **INC/DEC 최적화**: 단순히 1을 더하거나 뺄 때는 `a = a + 1`보다 `++a`나 `a++` 사용 권장 (CPU 명령어 `INC`로 변환되어 미세한 성능 이점 가능)
* **전위 vs 후위**: 반복문(`for`) 등에서 반환값을 당장 쓰지 않는다면, 임시 객체 생성이 없는 **전위 연산자(`++i`)**를 쓰는 것이 성능상 유리함
