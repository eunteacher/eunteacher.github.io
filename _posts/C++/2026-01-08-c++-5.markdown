# [C++] 문자와 문자열의 메모리 구조 및 인코딩

컴퓨터가 문자를 표현하는 기본 방식인 **ASCII**와, 전 세계 언어를 지원하기 위한 **유니코드(Unicode)**의 개념, 그리고 C++에서의 처리 방식(`char` vs `wchar_t`)을 정리

---

## 1. 소스 코드 (Source Code)

`char`와 `wchar_t`의 차이점, 그리고 문자열 끝에 들어가는 `Null(\0)` 문자의 존재를 확인하는 코드

```cpp
#include <iostream>
using namespace std;

int main()
{
    // 문자와 ASCII (1 Byte)
    // char는 내부적으로 '정수'지만 '문자'의 의미를 가짐
    char ch = 97;       // ASCII 97 = 'a'
    char ch2 = 'a';     // 문자 리터럴 사용
    char ch3 = '1';     // 숫자 1이 아닌 문자 '1' (ASCII 49)
    char ch4 = 'a' + 1; // 연산 가능: 97 + 1 = 98 ('b')

    // 유니코드와 wchar_t (2 Bytes in Windows)
    // 한글 등 다국어 처리를 위해 사용 (L 접두사 필요)
    wchar_t wch = L'안';
    wchar_t wch2 = 0xc548; // '안'의 유니코드 16진수 값

    // 문자열 (String)
    // 문자들이 열을 지어 모여 있는 것 (문자 배열)
    // 끝에는 반드시 \0 (Null)이 포함됨
    char str[] = { 'h', 'e', 'l','l' ,'o','\0' };
    char str2[] = "Hello World";    // 일반적으로 사용하는 방식
    wchar_t str3[] = L"안녕하세요";   // 유니코드 문자열

    // 출력 테스트
    cout << "Hello World!\n";
    cout << ch << endl;

    // 주의: cout은 char 전용이므로 wchar_t 출력 시 정수값이 나옴
    cout << wch << endl;

    // 해결: wcout 사용 및 로캘(Locale) 설정 필요
    wcout.imbue(locale("kor"));
    wcout << wch << endl;
    wcout << str3 << endl;

    return 0;
}
```

## 2. 이론 정리 (Study Notes)

### 1) 문자형 데이터 타입 (Character Types)
컴퓨터는 문자를 직접 저장하지 않고, 문자에 매핑된 **정수 번호**를 저장함

* **char:** 1바이트 (8비트). ASCII 코드 기반의 영문/숫자 표현
* **wchar_t:** 2바이트 (Windows 기준). 유니코드 표현을 위한 확장형 문자 타입. 리터럴 앞에 `L`을 붙여야 함 (예: `L'가'`)

### 2) 인코딩 (Encoding) 시스템

| 구분 | ASCII (아스키) | Unicode (유니코드) |
| :--- | :--- | :--- |
| **대상** | 영어, 숫자, 기본 특수문자 | 전 세계 모든 언어 (한글, 한자 등) |
| **크기** | 1 Byte (7 bit 사용) | 가변적 (UTF-8, UTF-16 등) |
| **특징** | 가장 기본적인 부호 체계 | 국제 표준, 플랫폼 간 호환성 중요 |

* **UTF-8:** 알파벳은 1바이트, 한글은 3바이트로 가변 저장 (메모리 효율적, 웹 표준)
* **UTF-16:** 대부분의 문자를 2바이트로 저장 (Windows 내부 시스템에서 주로 사용)

### 3) 이스케이프 시퀀스 (Escape Sequence)
표기하기 힘든 특수 문자를 백슬래시(`\`)로 표현하는 방법

* `\t`: 탭 (Tab)
* `\n`: 줄바꿈 (Line Feed)
* `\r`: 커서 앞으로 (Carriage Return)
* `\0`: 널 문자 (Null, 문자열의 끝)

### 4) 문자열의 구조
문자열은 **문자의 배열**이며, 길지가 가변적이기 때문에 **끝을 알리는 표식**이 필수적임

$$String = [char, char, char, ..., \mathbf{\backslash 0}]$$

* **Null Terminator (`\0`):** 아스키 코드 0번. 메모리 상에서 문자열이 여기서 끝난다는 것을 알리는 종료 문자
* `"Hello"`를 저장하려면 글자는 5개지만, 실제로는 `\0` 포함 **6바이트**가 필요함

## 3. 종합 의견 (Review)

* **출력 이슈 (Debugging):** C++ 입문 시 가장 많이 겪는 문제는 `wchar_t`를 `cout`으로 출력할 때 발생함
  * **현상:** 문자가 아닌 숫자(정수값)가 출력됨.
  * **해결:** `wcout`을 사용해야 하며, 특히 한글 출력 시 `wcout.imbue(locale("kor"))`와 같이 로캘 설정을 해줘야 깨지지 않음
* **글로벌 환경:** 현대의 소프트웨어는 다국어 지원이 필수적이므로, 단순 `char` 배열보다는 C++ 표준 라이브러리의 `std::string`이나 `std::wstring`을 사용하는 것이 메모리 관리와 호환성 면에서 훨씬 유리함
* **성능과 메모리:** 임베디드나 레거시 통신이 아니라면 UTF-8 기반의 처리가 네트워크 전송 등에서 표준으로 자리 잡고 있음
