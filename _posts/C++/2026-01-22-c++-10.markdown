# [C++] 이름이 보이는 범위와 값이 바뀌는 경계

---

## 스코프: 이름을 찾을 수 있는 범위

### 변수의 유효 범위 (Scope)
* **전역 변수 (Global Variable):** 프로그램 전체에서 접근 가능하며, 데이터 영역(Data Segment)에 저장
* **지역 변수 (Local Variable):** 선언된 블록과 그 안쪽 블록에서 이름을 사용할 수 있다. 일반적인 지역 변수는 자동 저장 기간을 갖지만, 스코프와 물리적 저장 위치는 같은 개념이 아니다.
* **이름 충돌 (Name Conflict):** 전역 변수와 지역 변수의 이름이 같을 경우, **지역 변수**가 우선순위를 가짐 (전역 변수는 가려짐)

## 타입 변환: 표현 가능한 값의 범위를 확인한다
* **데이터 손실 (Data Loss):** 대상 타입이 원래 값을 표현하지 못하면 값이 달라질 수 있다. 이를 단순히 모든 환경에서 “상위 비트가 물리적으로 잘린다”고 설명하면 안 된다.
* **부호 없는 타입 변환:** 정수는 대상 부호 없는 타입의 범위에 들어오도록 2의 거듭제곱을 법으로 한 값으로 변환된다. 메모리 복사 규칙이 아니라 값 변환 규칙이다.
* **실수 변환:** 정수를 실수(`float`)로 변환할 때 정밀도(Precision) 차이로 인한 근사값 처리가 발생할 수 있음

### 사칙 연산 주의사항
* **정수 나눗셈:** `int / int`의 결과는 항상 `int`임 (소수점 버림). 정확한 값을 얻으려면 피연산자 중 하나를 `float`로 캐스팅해야 함
* **0으로 나누기:** 수학적으로 불가능하며, 프로그램 크래시(Crash)의 주원인이 됨

## 변환 결과를 확인하는 코드

```cpp
#include <iostream>
using namespace std;

// [전역 변수]
// 프로그램 어디서든 접근 가능
int hp = 100;

int main()
{
    // [지역 변수]
    // main 함수 내부에서만 생존
    int hp = 10;

    // 이름 충돌: 지역 변수 hp가 전역 변수 hp를 가림
    cout << "Local hp: " << hp << endl; // 10 출력

    // 같은 스코프 내 중복 선언 불가
    // int hp = 50; // Error: 재정의 불가

#pragma region 타입 변환 (Type Casting)

    int mp = 10;

    // 1. 작은 타입으로 변환 (Downcasting)
    // 데이터 손실 없음 (범위 내)
    short s_mp = mp;

    // 2. 큰 값을 작은 타입으로 변환 (Overflow)
    mp = 77777; // 0x12FD1 (16진수)
    s_mp = mp;  // short는 2바이트(16비트)만 수용 가능

    // short가 이 값을 표현하지 못하면 결과는 구현 정의이다.
    cout << "Truncated Value: " << s_mp << endl;

    // 3. 부호 없는 타입으로 변환 (Unsigned)
    mp = -1; // 메모리: 1111 1111 ... (2의 보수)
    unsigned int ui_mp = mp;

    // unsigned int가 32비트라면 UINT_MAX가 된다.
    cout << "Unsigned Cast: " << ui_mp << endl;

#pragma endregion

#pragma region 산술 연산 (Arithmetic)

    // 1. 나눗셈의 함정 (정수 vs 실수)
    int max = 1000;
    int value = 123;

    // int / int = int (소수점 절삭)
    // 0.123 -> 0
    float ratio = value / max;
    cout << "Integer Div: " << ratio << endl;

    // 해결책: 명시적 형변환 (Explicit Casting)
    ratio = value / static_cast<float>(max);
    cout << "Float Div: " << ratio << endl;

    // 2. 0으로 나누기 (Divide By Zero)
    // max = 0;
    // ratio = value / max; // Runtime Error (Crash)

#pragma endregion

    return 0;
}
```
---
## 암시적 변환을 그냥 넘기지 않기

* **스코프의 우선순위:** 전역 변수와 지역 변수의 이름이 같으면 **지역 변수**가 우선
* **좁히기 변환:** 더 좁은 정수형으로 바꿀 때 원래 값이 대상 범위에 있는지 먼저 확인한다. 중괄호 초기화는 일부 좁히기 변환을 컴파일 단계에서 막아 준다.
* **나눗셈 연산:** 확률이나 비율 계산 시 `int / int`를 수행하여 결과가 0이 되는 버그가 빈번함. 반드시 `(float)` 캐스팅을 기억할 것

## C 스타일 캐스트보다 의도를 드러내기

### 연산자 우선순위와 괄호

* `a + b * c` 처럼 연산자가 섞여 있을 때 우선순위가 헷갈린다면, 굳이 외우려 하지 말고 **괄호 `()`**를 사용하는 것이 가장 좋음
* **예시:** `(a + b) * c` 또는 `a + (b * c)`
* 이는 컴파일러에게 의도를 명확히 전달하고, 코드를 읽는 사람(협업자)에게도 가독성을 제공

`(float)max`보다 `static_cast<float>(max)`가 검색하기 쉽고 허용하려는 변환 종류도 분명하다. 캐스트가 반복된다면 타입 설계나 계산 순서가 잘못된 것은 아닌지도 확인한다.

## 마무리

스코프는 이름 검색 규칙이고, 저장 기간은 객체가 살아 있는 시간이며, 캐스팅은 값을 다른 타입으로 변환하는 행위다. 서로 다른 문제를 “메모리 바구니” 하나로 묶지 않아야 정확한 코드를 작성할 수 있다.
