# [C++] 불리언(Boolean) 자료형의 이해

참(True)과 거짓(False)을 판별하는 논리형 데이터 **Boolean**의 개념과, 이것이 내부적으로 **왜 1바이트 정수**로 처리되는지에 대해 정리

---

## 1. 소스 코드 (Source Code)

`bool` 키워드를 사용하여 논리형 변수를 선언하고 값을 출력하는 예제

```cpp
#include <iostream>
using namespace std;

// [Boolean]: 참(True)과 거짓(False)을 다루는 자료형
// - 값: 0 (False), 0이 아닌 모든 수 (True, 주로 1)

// 변수명 앞에 'b'를 붙이는 것은 불리언임을 명시하는 작명 규칙 (헝가리안 표기법/언리얼 스타일)
bool bIsHighLevel = true;
bool bIsPlayer = true;
bool bIsMale = false;

int main()
{
    // true는 정수 1로 변환되어 출력됨
    cout << "bIsHighLevel: " << bIsHighLevel << endl;

    // false는 정수 0으로 출력됨
    cout << "bIsMale: " << bIsMale << endl;

    return 0;
}
```

## 2. 이론 정리 (Study Notes)

### 1) Boolean의 정의와 값
* **개념:** 오직 **참(True)**과 **거짓(False)** 두 가지 상태만을 가지는 논리 자료형
* **내부 값:**
  * `true` → **1** (대표값)
  * `false` → **0**

### 2) Boolean은 사실 '정수'다?
`bool` 타입을 공부할 때 가장 흥미로운 점은 내부적으로는 **1바이트 정수(Integer)**로 처리된다는 점

* **왜 정수형에서 같이 안 배우고 따로 배울까?**
  * **어셈블리 관점:** 어셈블리어에는 `bool`이라는 별도의 타입이 없음. `CMP`(비교) 명령어를 통해 결과가 0인지 아닌지를 판단
  * **C++ 관점:** `int`를 써도 되지만, **"이 변수는 참/거짓 판별용이다"**라는 **의도(Semantics)**를 명확히 하기 위해 `bool`을 따로 제공 (가독성 향상)

### 3) Boolean은 왜 1비트가 아니라 1바이트일까?
참/거짓은 0과 1, 즉 **1비트(Bit)**만 있어도 표현할 수 있다. 하지만 C++에서 `bool`은 **1바이트(8비트)**를 차지

* **이유:** CPU가 데이터를 주소(Address)로 접근할 때, **최소 단위가 바이트(Byte)**이기 때문입
* **상세:**
  * 우리가 메모리 주소를 가리킬 때 100번지, 101번지라고 하지, "100번지의 3번째 비트"라고 주소를 매기진 않음
  * 어셈블리의 최소 레지스터 단위도 `al`(1바이트)
  * 따라서 속도와 접근 효율성을 위해 1비트 정보를 저장하더라도 1바이트 공간을 사용

## 3. 종합 의견 (Review)

* **가독성(Readability):** `int isDead = 1;`보다 `bool bIsDead = true;`가 훨씬 직관적. 코드는 컴퓨터뿐만 아니라 사람이 읽는 것이기도 하므로 적절한 타입 사용이 중요
* **작명 팁:** 불리언 변수는 질문 형태(`Is`, `Can`, `Has`)로 짓는 것이 관례
  * `bIsRunning` (달리고 있는가?)
  * `bCanAttack` (공격 가능한가?)
