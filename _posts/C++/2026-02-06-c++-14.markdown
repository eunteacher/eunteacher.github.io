# [C++] 작은 게임도 생성과 판정을 나누면 단순해진다

`if-else`와 `switch-case` 제어문을 활용한 게임 로직 분기 처리와, `rand()` 함수를 이용한 난수 생성 방법을 실습하는 예제

---

## 먼저 동작하는 게임 만들기

컴퓨터와 가위바위보 대결을 반복하며 승률을 계산하는 프로그램

```cpp
#include <iostream>
#include <cstdlib> // rand(), srand()
#include <ctime>   // time()
using namespace std;

int main()
{
    // 1. 난수 테이블 초기화 (Seed 설정)
    // 시간(time)은 계속 흐르므로, 이를 시드값으로 주어 매번 다른 랜덤값이 나오게 함
    std::srand(static_cast<unsigned int>(std::time(0)));

    // 상수로 상태 정의 (매직 넘버 제거)
    const int WIN = 1;
    const int LOSE = 2;
    const int DRAW = 3;

    int Count = 0;    // 전체 판 수
    int WinCount = 0; // 승리 횟수
    int Result = 0;   // 현재 판 결과

    while (true)
    {
        cout << "1 : 주먹 \n2 : 보\n3 : 가위" << endl;
        cout << ">> ";

        int Input;
        cin >> Input;

        // 종료 조건: 1, 2, 3 이외의 숫자가 들어오면 루프 탈출
        if (Input < 1 || Input > 3)
        {
            break;
        }

        Count++; // 게임 횟수 증가

        // 컴퓨터의 선택 (1 ~ 3 사이의 난수 생성)
        int Random = rand() % 3 + 1;

        // 2. 승패 로직 판단
        if (Input == 1) // 플레이어: 주먹
        {
            switch (Random)
            {
            case 1: Result = DRAW; break; // 주먹 vs 주먹
            case 2: Result = LOSE; break; // 주먹 vs 보
            case 3: Result = WIN; WinCount++; break; // 주먹 vs 가위
            }
        }
        else if (Input == 2) // 플레이어: 보
        {
            switch (Random)
            {
            case 1: Result = WIN; WinCount++; break; // 보 vs 주먹
            case 2: Result = DRAW; break; // 보 vs 보
            case 3: Result = LOSE; break; // 보 vs 가위
            }
        }
        else if (Input == 3) // 플레이어: 가위
        {
            switch (Random)
            {
            case 1: Result = LOSE; break; // 가위 vs 주먹
            case 2: Result = WIN; WinCount++; break; // 가위 vs 보
            case 3: Result = DRAW; break; // 가위 vs 가위
            }
        }

        // 3. 승률 계산 및 결과 출력
        // 정수끼리의 나눗셈이므로 순서 주의: (승수 * 100) / 전체
        cout << "승률 : " << (WinCount * 100) / Count << "%" << endl;

        switch (Result)
        {
        case WIN:
            cout << "Win\n";
            break;
        case LOSE:
            cout << "Lose\n";
            break;
        case DRAW:
            cout << "Draw\n";
            break;
        }
        cout << "--------------------" << endl;
    }

    return 0;
}
```

## 의사 난수와 범위 변환

### 2.1 난수 생성 (Random Generation)

컴퓨터는 규칙에 따라 움직이기 때문에 진정한 의미의 '무작위'를 만들어낼 수 없음. 따라서 특정 알고리즘에 따라 난수처럼 보이게 만드는 **의사 난수(Pseudo-Random)**를 사용

* **`std::rand()`**: 0부터 `RAND_MAX` 사이의 정수를 반환한다. `RAND_MAX`의 실제 값은 구현마다 다르다.
* **`std::srand(seed)`**: 난수표의 시작점(Seed)을 설정하는 함수. 시드값이 같으면 항상 같은 순서의 난수가 나옴
* **`std::time(0)`**: 1970년 1월 1일부터 현재까지 흐른 시간을 초 단위로 반환. 실행할 때마다 값이 변하므로 시드값으로 적합함

**범위 지정 공식:**
$$RandomValue = (\text{rand}() \pmod n) + min$$

* $n$: 필요한 숫자의 개수 (범위의 크기)
* $min$: 시작 숫자
* **예시 (1 ~ 3):** `rand() % 3 + 1`

### 2.2 제어문 활용 (switch vs if)

* **`if-else`**: 복잡한 조건식이나 범위 판별에 유리
* **`switch-case`**: 하나의 정수형·열거형 값에 따라 분기할 때 의도가 선명하다. 점프 테이블 사용 여부는 컴파일러가 판단하므로 성능을 선택 기준으로 삼지 않는다.
* **적용**: 이 예제에서는 플레이어의 입력은 `if`로 분기하고, 내부에서 컴퓨터의 값에 따른 결과는 `switch`로 처리하여 구조를 잡음

### 2.3 상수(const)의 활용

`WIN = 1`, `LOSE = 2` 처럼 의미 없는 숫자(Magic Number)를 그대로 쓰지 않고 `const` 변수로 이름을 붙여 사용

* **가독성 향상**: `case 1:` 보다 `case WIN:`이 훨씬 직관적임
* **유지보수 용이**: 값이 바뀌어도 선언부만 수정하면 됨

## 생성·입력·판정을 각각 검증하기

### 핵심 요약 및 주의사항

* **정수 나눗셈의 순서**: 승률 계산 시 `(WinCount / Count) * 100`을 하면 버그가 발생함
  * C++에서 정수 나누기 정수는 소수점을 버리므로 `WinCount < Count`인 경우 결과가 항상 **0**이 됨
  * 따라서 **`(WinCount * 100) / Count`** 처럼 곱셈을 먼저 수행하여 값을 키운 뒤 나눠야 함
* **반복문 탈출**: `while(true)` 무한 루프를 사용할 때는 반드시 명확한 **종료 조건(`break`)**이 있어야 함. 여기서는 `else` 블록(1, 2, 3 외의 입력)이 그 역할을 함.

### Tip

* **Enum의 활용**: `const int` 대신 `enum`을 사용하면 연관된 상수들을 그룹화하여 관리하기 더 편함
    ```cpp
    enum class GameResult { WIN, LOSE, DRAW };
    enum class Hand { ROCK = 1, PAPER = 2, SCISSORS = 3 };
    ```
* **난수의 한계**: `rand()`는 간단하지만 정밀한 난수가 아님. 암호학적으로 안전하거나 고품질의 난수가 필요하다면 C++11의 `<random>` 라이브러리(`std::mt19937` 등) 사용을 권장함

`rand() % 3`은 원본 난수 범위가 3으로 정확히 나누어떨어지지 않으면 작은 편향이 생긴다. 학습 예제에서는 동작하지만, 현대 C++ 코드라면 `std::uniform_int_distribution<int>`로 원하는 분포를 표현하는 편이 낫다.

게임 결과 판정은 난수 생성과 분리해 `Judge(player, computer)` 같은 순수 함수로 만들면 모든 조합을 고정된 입력으로 테스트할 수 있다. 재현 가능한 테스트가 필요할 때는 시드도 외부에서 전달한다.
