# [어셈블리] 반복문 구현과 LOOP 명령어

## 1. 소스 코드 (Source Code)
`CMP`와 `JMP`를 이용한 수동 반복문 구현과, `ECX` 레지스터를 기반으로 동작하는 `LOOP` 명령어를 비교하는 예제
1부터 100까지의 합(Summation)을 구하는 세 가지 방식을 포함

```nasm
%include "io64.inc"

section .text
global CMAIN
CMAIN:
    mov rbp, rsp; for correct debugging

    ; 1. 기본 반복문 (CMP + JMP)
    ; Hello World를 10번 출력

    mov ecx, 10         ; 카운터 초기화 (10회)

LABEL_LOOP:
    PRINT_STRING msg
    NEWLINE

    dec ecx             ; ecx = ecx - 1 (Counter 감소)
    cmp ecx, 0          ; 0인지 확인
    jne LABEL_LOOP      ; 0이 아니면(ZF=0) 다시 라벨로 점프


    ; 2. 연습 문제: 1부터 100까지의 합 구하기

    ; [방법 1] 증가 연산 (INC) 활용
    ; 1 + 2 + ... + 100

    mov eax, 100        ; 최종 목적지 (N)
    xor ebx, ebx        ; 결과값 누적용 (ebx = 0 초기화, mov보다 빠름)
    xor ecx, ecx        ; 카운터 (i = 0)

LABEL_SUM_MANUAL:
    inc ecx             ; i++
    add ebx, ecx        ; sum += i

    cmp ecx, eax        ; i == 100 ?
    jne LABEL_SUM_MANUAL

    PRINT_DEC 4, ebx    ; 결과 출력 (5050)
    NEWLINE


    ; [방법 2] LOOP 명령어 활용
    ; 100 + 99 + ... + 1 (순서는 반대지만 합은 동일)

    mov ecx, 100        ; 반복 횟수 설정 (LOOP 명령은 ECX를 참조함)
    xor ebx, ebx        ; 결과값 초기화

LABEL_LOOP_SUM:
    add ebx, ecx        ; sum += ecx

    loop LABEL_LOOP_SUM ; [핵심] ecx--, if(ecx != 0) goto Label

    PRINT_DEC 4, ebx    ; 결과 출력 (5050)
    NEWLINE

    xor rax, rax
    ret

section .data
    msg db 'Hello World', 0x00
```

## 2. 이론 정리 (Study Notes)

### 2.1 반복문의 구조
* 어셈블리어에는 고수준 언어의 `while`이나 `for`문이 직접적으로 존재하지 않음. 대신 **조건 분기(Jump)**를 이용하여 구현
* **구조**: `초기값 설정` $\rightarrow$ `본문 실행` $\rightarrow$ `증감(DEC/INC)` $\rightarrow$ `조건 확인(CMP)` $\rightarrow$ `점프(JMP)`

### 2.2 LOOP 명령어
반복문의 패턴(`DEC ECX` + `CMP ECX, 0` + `JNE`)을 하나의 명령어로 축약한 것

* **동작 원리**:
  1. `ECX` 레지스터의 값을 1 감소시킴 (`DEC ECX`)
  2. `ECX`가 0이 아니면 지정된 라벨로 점프함 (`JNE`)
  3. `ECX`가 0이면 다음 명령어로 넘어감
* **특징**: 무조건 **`ECX` 레지스터**를 카운터로 사용해야 한다는 제약이 있음

### 2.3 주요 연산 명령어 정리

| 명령어 | 설명 | 특징 |
| :--- | :--- | :--- |
| **`INC reg`** | `reg` 값을 1 증가시킴 | `ADD reg, 1`보다 명령어 길이가 짧고 빠를 수 있음 |
| **`DEC reg`** | `reg` 값을 1 감소시킴 | `SUB reg, 1`과 동일 효과 |
| **`XOR reg, reg`** | `reg` 값을 0으로 초기화 | `MOV reg, 0`보다 빠르고 기계어 코드가 짧음 |
| **`LOOP label`** | `ECX`를 1 줄이고 0이 아니면 점프 | 코드가 간결해지지만 `ECX` 사용 강제됨 |

### 2.4 등차수열의 합 (검증)
1부터 100까지의 합이 맞는지 수학적으로 검증
$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$
$$\frac{100 \times 101}{2} = 5050$$

## 3. 종합 의견 (Review)

### 핵심 요약 및 주의사항
* **`ECX` 레지스터 관리**: `LOOP` 명령어 사용 시, 루프 내부에서 `ECX` 값을 변경하면 반복 횟수가 꼬이게 됨. 만약 내부에서 `ECX`가 필요하다면 스택에 백업(`PUSH`/`POP`)하거나 다른 레지스터를 사용해야 함
* **초기화의 중요성**: 반복문에서 누적 변수(`sum`)나 카운터 변수는 루프 진입 전에 반드시 초기화(`MOV` or `XOR`)해야 쓰레기 값에 의한 오류를 방지할 수 있음

### Tip
* **`MOV` vs `XOR`**: 레지스터를 0으로 만들 때 `mov rax, 0`을 쓰면 명령어를 처리할 때 '0'이라는 데이터를 가져오는 과정이 필요함. 반면 `xor rax, rax`는 같은 값끼리 비트 연산(Exclusive OR)을 하면 무조건 0이 되는 논리를 이용하므로 CPU 입장에서 더 빠르고 효율적임
  * $1 \oplus 1 = 0$
  * $0 \oplus 0 = 0$
