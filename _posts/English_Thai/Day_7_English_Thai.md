# Day 7 --- English & Thai Conversation

## 🇺🇸 English

### 1. 나 먼저 잘게.

**I'm going to bed first.**\
*(아임 고잉 투 베드 퍼스트.)*

- **I'm going to bed** = 나 잘 거야 / 자러 갈게
- **first** = 먼저

### 2. 이제 안 잘 거야.

**I'm not going to sleep anymore.**\
*(아임 낫 고잉 투 슬립 애니모어.)*

- **I'm not going to ~** = ~하지 않을 거야
- **sleep** = 자다
- **anymore** = 더 이상 / 이제는

### 3. 왜 이렇게 오래 걸려? / 너무 오래 걸리네.

**It's taking so long.**\
*(잇츠 테이킹 쏘 롱.)*

- **take** = 시간이 걸리다
- **taking** = 시간이 걸리고 있는 중
- **so long** = 너무 오래

### 4. 나 기다리고 있어.

**I'm waiting.**\
*(아임 웨이팅.)*

- **I'm ~ing** = 나는 지금 ~하고 있어
- **wait** = 기다리다
- **waiting** = 기다리고 있다

### 5. 조금만 기다려.

**Wait a moment.**\
*(웨잇 어 모먼트.)*

- **wait** = 기다리다
- **a moment** = 잠깐
- **Wait a second.** = 잠깐만 기다려 / 잠깐만
- **Wait a moment.** = 잠시만 기다려

### 6. 내일 나 일찍 일어나야 해.

**I have to wake up early tomorrow.**\
*(아이 해브 투 웨이크 업 얼리 투모로우.)*

- **I have to ~** = 나는 ~해야 해
- **wake up** = 일어나다 / 잠에서 깨다
- **early** = 일찍
- **tomorrow** = 내일

### 7. 내일 나 약속이 있어.

**I have plans tomorrow.**\
*(아이 해브 플랜즈 투모로우.)*

- **have plans** = 약속 / 일정이 있다
- **tomorrow** = 내일
- 보통 일상적인 약속이나 일정은 **I have plans**라고 자연스럽게 말함

## 🇹🇭 Thai

### 1. 나 먼저 잘게.

**นอนก่อนนะ**\
*(넌 껀 나)*

- **นอน (넌)** = 자다
- **ก่อน (껀)** = 먼저
- **นะ (나)** = 말을 부드럽게 만드는 어미

### 2. 이제 안 잘 거야.

**ไม่นอนแล้ว**\
*(마이 넌 래우)*

- **ไม่ (마이)** = ~하지 않다 / 안
- **นอน (넌)** = 자다
- **แล้ว (래우)** = 이제 / 이미 / 상태가 바뀌었음을 나타냄

### 3. 왜 이렇게 오래 걸려? / 너무 오래 걸리네.

**นานจัง**\
*(난 짱)*

- **นาน (난)** = 오래 / 오랫동안
- **จัง (짱)** = 정말 / 너무 / 되게 (감탄)

### 4. 나 기다리고 있어.

**ผมกำลังรออยู่**\
*(폼 깜랑 러 유)*

- **ผม (폼)** = 나 / 저 (남성이 사용)
- **กำลัง (깜랑)** = ~하고 있는 중
- **รอ (러)** = 기다리다
- **อยู่ (유)** = ~하고 있다
- **กำลัง + 동사 + อยู่** = 지금 ~하고 있는 중이다

### 5. 조금만 기다려.

**รอแป๊บนึงนะ**\
*(러 뺍 능 나)*

- **รอ (러)** = 기다리다
- **แป๊บนึง (뺍 능)** = 잠깐 / 조금만
- **นะ (나)** = 말을 부드럽게 만드는 어미

### 6. 내일 나 일찍 일어나야 해.

**พรุ่งนี้ผมต้องตื่นเช้านะ**\
*(프룽니 폼 떵 뜬 차오 나)*

- **พรุ่งนี้ (프룽니)** = 내일
- **ผม (폼)** = 나 / 저
- **ต้อง (떵)** = ~해야 한다
- **ตื่น (뜬)** = 일어나다 / 잠에서 깨다
- **เช้า (차오)** = 아침 / 일찍
- **ต้อง + 동사** = ~해야 한다

### 7. 내일 나 약속이 있어.

**พรุ่งนี้ผมมีนัดนะ**\
*(프룽니 폼 미 낫 나)*

- **พรุ่งนี้ (프룽니)** = 내일
- **ผม (폼)** = 나 / 저
- **มี (미)** = 있다 / 가지고 있다
- **นัด (낫)** = 약속 / 일정
- **มีนัด (미 낫)** = 약속이 있다
- **นะ (나)** = 말을 부드럽게 만드는 어미
