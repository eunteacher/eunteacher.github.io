# Day 1 --- English & Thai Conversation

## 🇺🇸 English

### Q. 어제 뭐 했어?

**What did you do yesterday?**\
*(왓 디쥬 두 예스터데이?)*

- **What (왓)** = 무엇 / 뭐
- **did you do (디쥬 두)** = 너는 무엇을 했어?
- **yesterday (예스터데이)** = 어제
- **What did you do ~?** = 너는 ~에 뭐 했어?

### A. 어제는 엄마 생일이었어. 그래서 같이 스시 먹었어.

**Yesterday was my mom's birthday, so we had sushi together.**\
*(예스터데이 워즈 마이 맘스 벌스데이, 쏘 위 해드 스시 투게더.)*

- **Yesterday (예스터데이)** = 어제
- **my mom's birthday (마이 맘스 벌스데이)** = 우리 엄마의 생일
- **so (쏘)** = 그래서
- **had sushi (해드 스시)** = 스시를 먹었다
- **together (투게더)** = 함께 / 같이
- **have → had** = 먹다 → 먹었다 (음식을 말할 때)

### Q. 오늘 뭐 했어?

**What did you do today?**\
*(왓 디쥬 두 투데이?)*

- **What (왓)** = 무엇 / 뭐
- **did you do (디쥬 두)** = 너는 무엇을 했어?
- **today (투데이)** = 오늘
- **did** = 과거의 행동을 물을 때 사용하는 do의 과거형

### A. 일했어.

**I worked.**\
*(아이 워크트.)*

- **I (아이)** = 나
- **worked (워크트)** = 일했다
- **work → worked** = 일하다 → 일했다

## 🇹🇭 Thai

### Q. 어제 뭐 했어?

**เมื่อวานทำอะไรมา?**\
*(므어완 탐 아라이 마?)*

- **เมื่อวาน (므어완)** = 어제
- **ทำ (탐)** = 하다
- **อะไร (아라이)** = 무엇 / 뭐
- **มา (마)** = 오다 / 여기서는 지금까지 한 행동을 묻는 뉘앙스
- **ทำอะไรมา? (탐 아라이 마?)** = 뭐 했어? / 뭐 하고 왔어?

### A. 어제는 엄마 생일이었어.

**เมื่อวานเป็นวันเกิดแม่ผม**\
*(므어완 뻰 완 끄엇 매 폼)*

- **เมื่อวาน (므어완)** = 어제
- **เป็น (뻰)** = ~이다
- **วันเกิด (완 끄엇)** = 생일
- **แม่ (매)** = 엄마
- **ผม (폼)** = 나 / 저 (남성이 사용)
- **แม่ผม (매 폼)** = 우리 엄마 / 제 엄마

### A. 그래서 저녁에 같이 스시 먹었어.

**ก็เลยกินซูชิด้วยกันตอนเย็น**\
*(꺼 러이 낀 수시 두어이 깐 떤 옌)*

- **ก็เลย (꺼 러이)** = 그래서
- **กิน (낀)** = 먹다
- **ซูชิ (수시)** = 스시
- **ด้วยกัน (두어이 깐)** = 같이 / 함께
- **ตอนเย็น (떤 옌)** = 저녁에

### Q. 오늘 뭐 했어?

**วันนี้ทำอะไรมา?**\
*(완니 탐 아라이 마?)*

- **วันนี้ (완니)** = 오늘
- **ทำ (탐)** = 하다
- **อะไร (아라이)** = 무엇 / 뭐
- **มา (마)** = 오다 / 여기서는 지금까지 한 행동을 묻는 뉘앙스
- **ทำอะไรมา? (탐 아라이 마?)** = 뭐 했어? / 뭐 하고 왔어?

### A. 오늘 일했어.

**วันนี้ผมทำงาน**\
*(완니 폼 탐 응안)*

- **วันนี้ (완니)** = 오늘
- **ผม (폼)** = 나 / 저 (남성이 사용)
- **ทำงาน (탐 응안)** = 일하다
- **งาน (응안)** = 일 / 업무
