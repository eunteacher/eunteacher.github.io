# [C++] Hello World 출력 및 개발 환경 기초 정리

C++ 언어를 공부하며 작성한 `Hello World` 출력 코드와, 이 과정에서 익힌 Visual Studio(IDE)의 주요 기능 및 프로젝트 관리 방법들을 정리

---

## 1. 소스 코드 (Source Code)

`iostream` 라이브러리를 포함하여 콘솔창에 텍스트를 출력하는 가장 기초적인 C++ 코드

```cpp
#include <iostream>

/** Hello World 출력하기 */

// 1_HelloWorld.cpp : 이 파일에는 'main' 함수가 포함
// 거기서 프로그램 실행이 시작되고 종료

int main()
{
    // Hello World 출력
    std::cout << "Hello World!\n";
}
```

---

## 2. 이론 정리 (Study Notes)

위의 간단한 `Hello World` 코드가 실행되기 위해 필요한 C++의 핵심 개념들을 분석

### 2.1 전처리 지시자 (`#include`)
* **`#include <iostream>`**: 'Input/Output Stream'의 약자로, 입출력 작업을 위한 표준 라이브러리 헤더 파일
* C++ 컴파일러가 소스 코드를 컴파일하기 전에, 이 헤더 파일의 내용을 현재 파일로 가져오도록(포함하도록) 지시
* 이것이 있어야 `std::cout` 같은 기능을 사용

### 2.2 메인 함수 (`main`)
* **`int main()`**: C++ 프로그램의 **진입점(Entry Point)**
* 프로그램이 실행되면 운영체제는 가장 먼저 이 `main` 함수를 찾아 호출
* 함수 앞에 붙은 `int`는 반환형(Return Type)을 의미하며, 프로그램이 정상적으로 종료되었을 때 운영체제에 `0`을 반환하는 것이 관례 (C++ 표준에서는 `return 0;`을 생략해도 묵시적으로 0을 반환함)

### 2.3 표준 입출력 (`std::cout`)
* **`std`**: **네임스페이스(Namespace)**라고 부름. 이름 충돌을 방지하기 위해 표준 라이브러리의 기능들이 모여 있는 소속 공간
* **`cout`**: 'Character Output'의 약자로, 콘솔 창에 문자를 출력하는 객체
* **`::`**: **범위 지정 연산자(Scope Resolution Operator)**. "std라는 소속 안에 있는 cout을 쓰겠다"는 의미
* **`<<`**: **삽입 연산자(Insertion Operator)**. 오른쪽의 데이터("Hello World!\n")를 왼쪽의 출력 스트림(`cout`)으로 보낸다는 뜻
* **`\n`**: 줄 바꿈(New Line)을 의미하는 이스케이프 문자. `std::endl`을 사용해도 무방

## 3. Visual Studio 개발 환경 기초

Visual Studio를 사용하며 알게 된 프로젝트 구조와 필수 단축키 정리

### 3.1 솔루션(Solution)과 프로젝트(Project)의 차이
Visual Studio의 파일 관리 체계는 **솔루션 > 프로젝트** 구조

* **솔루션 (`.sln`)**: 하나의 거대한 컨테이너. 여러 개의 프로젝트를 담을 수 있음 (예: 게임 전체)
* **프로젝트 (`.vcxproj`)**: 실제 소스 코드와 설정들이 들어가는 단위 (예: 게임 엔진, 게임 클라이언트, 서버 툴 등)
* **파일 관리 팁**: 실제 소스 파일(`.cpp`, `.h`) 외에 솔루션 파일(`.sln`)이 있어야 프로젝트를 통째로 다시 열 수 있음

### 3.2 빌드 및 실행 과정
1. **전처리 (Preprocessing)**: `#include` 등의 지시자를 처리하고 소스 코드를 정리
2. **컴파일 (Compiling)**: 사람이 작성한 C++ 코드를 기계어(Object 파일)로 번역. 문법 오류는 여기서 찾음
3. **링킹 (Linking)**: 여러 개의 Object 파일과 라이브러리를 합쳐 하나의 실행 파일(`.exe`) 생성
4. **실행**: 생성된 `.exe` 파일을 메모리에 적재하여 실행

### 3.3 유용한 단축키
* **F5 (Start Debugging)**: 디버깅 모드로 실행. 중단점(Breakpoint)을 설정하면 거기서 멈춤
* **Ctrl + F5 (Start Without Debugging)**: 디버깅 없이 바로 실행. 콘솔 창이 바로 꺼지지 않고 결과를 확인할 수 있어 편리
* **F7 (Build Solution)**: 코드를 실행하지 않고 빌드(컴파일+링킹)만 수행하여 오류를 체크

### [참고] 코드 작성 시 주의사항 (Common Mistakes)
* C++의 모든 명령문은 반드시 **세미콜론(`;`)**으로 끝남
* `iostream`과 같은 표준 헤더 파일은 확장자(`.h`)를 붙이지 않음 (C언어 헤더와 구별됨)
